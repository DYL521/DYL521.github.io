Linux网络命令

操作系统 2021-02-13 · 17 分钟阅读 · 4876 字

01.概述

Linux 下的网络命令大致分两代：

  • net-tools（老一代）：ifconfig、route、netstat、arp。很多新发行版（如 CentOS/RHEL 8+、较新的 Debian/Ubuntu 最小化安装）默认已不再预装。
  • iproute2（新一代）：ip、ss。功能更强、性能更好，是目前推荐使用的工具。
功能 net-tools iproute2
查看网卡/IP ifconfig ip addr（ip a）
启停网卡 ifconfig eth0 up/down ip link set eth0 up/down
查看路由 route -n ip route（ip r）
查看 ARP 表 arp -n ip neigh
查看连接/端口 netstat -tunlp ss -tunlp

老系统上缺少 ifconfig / netstat 时可安装 net-tools 包：yum install -y net-tools 或 apt install -y net-tools。

02.查看与配置 IP

2.1 ip 命令

ip addr                          # 查看所有网卡的 IP
ip -br a                         # 简洁格式输出
ip link                          # 查看网卡状态、MAC 地址
ip addr add 192.168.1.100/24 dev eth0   # 临时添加 IP
ip addr del 192.168.1.100/24 dev eth0   # 删除 IP
ip link set eth0 down            # 关闭网卡
ip link set eth0 up              # 启用网卡
ip -s link show eth0             # 查看收发包统计

2.2 ifconfig 命令

ifconfig                         # 查看已启用网卡
ifconfig -a                      # 查看所有网卡（包括未启用的）
ifconfig eth0 192.168.1.100 netmask 255.255.255.0   # 临时设置 IP

注意：ip 和 ifconfig 的修改都是临时的，重启后失效。永久配置需要写网络配置文件或使用 NetworkManager。

2.3 永久配置（NetworkManager / nmcli）

RHEL/CentOS 7 之后普遍使用 NetworkManager，推荐用 nmcli 修改：

nmcli device status                      # 查看设备状态
nmcli connection show                    # 查看连接
nmcli connection modify eth0 \
    ipv4.method manual \
    ipv4.addresses 192.168.1.100/24 \
    ipv4.gateway 192.168.1.1 \
    ipv4.dns "223.5.5.5 114.114.114.114"
nmcli connection up eth0                 # 使配置生效

旧版 CentOS 7 也可以直接编辑 /etc/sysconfig/network-scripts/ifcfg-eth0；RHEL 9 默认改为 /etc/NetworkManager/system-connections/*.nmconnection 格式。Ubuntu 18.04 之后则使用 netplan（/etc/netplan/*.yaml，修改后执行 netplan apply）。

03.路由与网关

ip route                                 # 查看路由表
ip route add default via 192.168.1.1     # 添加默认网关
ip route add 10.0.0.0/8 via 192.168.1.254 dev eth0   # 添加静态路由
ip route del 10.0.0.0/8                  # 删除路由
ip route get 8.8.8.8                     # 查看访问某地址会走哪条路由
route -n                                 # 老命令，-n 表示不解析主机名

04.连通性测试

4.1 ping

ping -c 4 www.baidu.com          # 发 4 个包后停止（Linux 默认会一直发）
ping -i 0.2 -c 10 192.168.1.1    # 间隔 0.2 秒
ping -W 2 192.168.1.1            # 超时时间 2 秒

ping 使用的是 ICMP 协议，ping 不通不代表服务不可用（可能是防火墙禁止了 ICMP），ping 得通也不代表端口可达。

4.2 路由追踪

traceroute www.baidu.com         # 追踪经过的路由节点
tracepath www.baidu.com          # 无需 root，部分系统自带
mtr www.baidu.com                # ping + traceroute 的结合，持续统计丢包

4.3 端口连通性

telnet 192.168.1.10 3306                 # 经典方式
nc -zv 192.168.1.10 3306                 # 用 nc 检测端口
nc -zv 192.168.1.10 20-25                # 扫描端口范围
curl -v telnet://192.168.1.10:6379       # 没有 telnet/nc 时可用 curl
timeout 3 bash -c '</dev/tcp/192.168.1.10/22' && echo open   # 纯 bash 方式

05.端口与连接查看

5.1 ss（推荐）

ss -tunlp                        # 查看所有监听的 TCP/UDP 端口及进程
ss -tnp state established        # 查看已建立的 TCP 连接
ss -s                            # 连接数统计汇总
ss -tn sport = :80               # 过滤源端口为 80 的连接
ss -ant | awk 'NR>1{print $1}' | sort | uniq -c   # 统计各 TCP 状态数量

参数含义：-t TCP、-u UDP、-n 不解析服务名、-l 只看监听、-p 显示进程（查看其他用户的进程需要 root）、-a 全部。

5.2 netstat

netstat -tunlp                   # 与 ss -tunlp 类似
netstat -an | grep :80           # 查看 80 端口相关连接

ss 直接从内核获取信息，在连接数很多时比 netstat 快得多。

5.3 lsof

lsof -i :8080                    # 查看哪个进程占用了 8080 端口
lsof -i tcp                      # 查看所有 TCP 连接

06.DNS 相关

cat /etc/resolv.conf             # DNS 服务器配置
cat /etc/hosts                   # 本地域名解析
dig www.baidu.com                # 详细的 DNS 查询
dig +short www.baidu.com         # 只输出结果
dig @223.5.5.5 www.baidu.com     # 指定 DNS 服务器
nslookup www.baidu.com           # 简单查询
host www.baidu.com

dig、nslookup、host 在 RHEL 系属于 bind-utils 包，Debian/Ubuntu 中属于 dnsutils（或 bind9-dnsutils）包。

07.HTTP 与下载

curl -I https://www.baidu.com            # 只看响应头
curl -o file.zip https://example.com/a.zip   # 下载并指定文件名
curl -X POST -H "Content-Type: application/json" \
     -d '{"name":"dyl"}' http://localhost:8080/api/user
curl -w "%{http_code} %{time_total}\n" -o /dev/null -s https://www.baidu.com   # 状态码与耗时
wget -c https://example.com/big.iso      # 断点续传下载

08.抓包与主机名

tcpdump -i eth0 port 80 -nn              # 抓取 80 端口的包
tcpdump -i any host 192.168.1.10 -w a.pcap   # 保存为文件，可用 Wireshark 分析
hostname                                 # 查看主机名
hostnamectl set-hostname web01           # 永久修改主机名（systemd 系统）

09.常见排查思路

网络不通时可以按"由近及远"的顺序排查：

  1. ip a 看网卡是否 UP、是否有 IP。
  2. ip route 看是否有默认网关，ping 网关 测试局域网。
  3. ping 8.8.8.8 测试外网 IP 连通性。
  4. ping 域名 / dig 域名 判断是否是 DNS 问题。
  5. 服务访问不了：服务端 ss -tunlp 确认端口是否在监听，注意监听地址是 127.0.0.1 还是 0.0.0.0；客户端用 nc -zv 测端口；再检查防火墙 firewall-cmd --list-all 或 iptables -nL / nft list ruleset，云服务器还要检查安全组。

小结

  • 新系统优先使用 iproute2：ip a、ip r、ip link、ss -tunlp；ifconfig、netstat 了解即可。
  • 命令行修改 IP 是临时的，永久修改用 nmcli 或对应发行版的配置文件。
  • 连通性测试分层次：ping 测三层、nc/telnet 测端口、curl 测应用层、dig 测 DNS。
  • 端口占用排查：ss -tunlp | grep 端口 或 lsof -i :端口。
