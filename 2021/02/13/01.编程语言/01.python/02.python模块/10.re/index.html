01.re模块是什么

正则表达式（Regular Expression）是一种描述字符串规则的“小语言”，用来匹配、查找、提取、替换文本。Python 通过标准库 re 提供正则支持。

典型场景：校验手机号/邮箱格式、从日志中提取 IP 和时间、批量替换文本、按复杂规则切分字符串。

写正则时一定使用原始字符串 r"..."，否则 \d、\b 这类反斜杠会先被 Python 字符串转义一遍（例如 "\b" 是退格符）。

02.基础语法

2.1 普通字符与元字符

写法 含义
. 匹配除换行符外的任意单个字符
^ / $ 字符串开头 / 结尾
\d / \D 数字 / 非数字
\w / \W 单词字符（字母、数字、下划线，Unicode 下也包括汉字）/ 非单词字符
\s / \S 空白字符 / 非空白字符
\b 单词边界
[abc] 字符集，匹配 a、b、c 中任意一个
[^abc] 取反，匹配不是 a、b、c 的字符
[a-z0-9] 范围
a|b 或
\ 转义，如 \. 匹配真正的点

2.2 量词

写法 含义
* 0 次或多次
+ 1 次或多次
? 0 次或 1 次
{n} 恰好 n 次
{n,} 至少 n 次
{n,m} n 到 m 次

2.3 分组

写法 含义
(...) 捕获分组
(?P<name>...) 命名分组
(?:...) 非捕获分组，只分组不保存
\1 / (?P=name) 反向引用前面分组匹配到的内容
(?=...) / (?!...) 正向先行断言 / 负向先行断言
(?<=...) / (?<!...) 正向后行断言 / 负向后行断言

03.常用函数

import re

text = "订单 1001 金额 25.5 元，订单 1002 金额 8 元"

# 1. re.match：只从字符串【开头】匹配
print(re.match(r"\d+", text))          # None，开头是“订单”
print(re.match(r"订单", text).group())  # 订单

# 2. re.search：扫描整个字符串，返回第一个匹配
m = re.search(r"\d+", text)
print(m.group(), m.start(), m.end(), m.span())   # 1001 3 7 (3, 7)

# 3. re.fullmatch：整个字符串必须完全匹配，适合做格式校验
print(bool(re.fullmatch(r"1[3-9]\d{9}", "13812345678")))   # True

# 4. re.findall：返回所有匹配的列表
print(re.findall(r"\d+(?:\.\d+)?", text))   # ['1001', '25.5', '1002', '8']

# 5. re.finditer：返回迭代器，元素是 Match 对象，适合大文本
for m in re.finditer(r"订单 (\d+)", text):
    print(m.group(1), m.span())

# 6. re.sub：替换
print(re.sub(r"\d+", "#", "a1b22c333"))      # a#b#c#
print(re.sub(r"\d+", "#", "a1b22c333", count=1))   # a#b22c333

# 7. re.split：按正则切分
print(re.split(r"[,;\s]+", "a, b;c   d"))    # ['a', 'b', 'c', 'd']

match / search / fullmatch 匹配失败时返回 None，直接 .group() 会报 AttributeError，使用前要判断：

if m := re.search(r"\d+", "abc"):
    print(m.group())
else:
    print("没找到")

04.分组提取

import re

log = "2024-03-15 10:23:45 ERROR 192.168.1.10 连接超时"

pattern = r"(?P<date>\d{4}-\d{2}-\d{2}) (?P<time>[\d:]+) (?P<level>\w+) (?P<ip>[\d.]+)"
m = re.search(pattern, log)

print(m.group())           # 整个匹配
print(m.group(1))          # 2024-03-15
print(m.group("level"))    # ERROR
print(m.groups())          # ('2024-03-15', '10:23:45', 'ERROR', '192.168.1.10')
print(m.groupdict())       # {'date': '2024-03-15', 'time': '10:23:45', 'level': 'ERROR', 'ip': '192.168.1.10'}

sub 中可以引用分组，也可以传入函数：

import re

# 日期格式 2024-03-15 -> 15/03/2024
print(re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\3/\2/\1", "2024-03-15"))

# 传函数：把所有数字乘以 2
print(re.sub(r"\d+", lambda m: str(int(m.group()) * 2), "a1b20"))   # a2b40

05.贪婪与非贪婪

量词默认是贪婪的，会尽可能多地匹配；在量词后加 ? 变成非贪婪，尽可能少地匹配。

import re

html = "<b>加粗</b><i>斜体</i>"

print(re.findall(r"<.+>", html))    # ['<b>加粗</b><i>斜体</i>']  贪婪，一口气吃到最后
print(re.findall(r"<.+?>", html))   # ['<b>', '</b>', '<i>', '</i>']  非贪婪

06.编译与标志位

同一个正则需要反复使用时，可以先 re.compile，代码也更清晰（re 内部对模式有缓存，所以性能差异通常不大）。

import re

EMAIL = re.compile(r"^[\w.+-]+@[\w-]+(\.[\w-]+)+$")
print(bool(EMAIL.match("test@example.com")))   # True

# 常用标志
re.findall(r"python", "Python PYTHON", flags=re.IGNORECASE)   # 忽略大小写
re.findall(r"^\d+", "1a\n2b\n3c", flags=re.MULTILINE)       # ^ $ 匹配每一行 -> ['1', '2', '3']
re.search(r"a.b", "a\nb", flags=re.DOTALL)                   # . 也匹配换行

# re.VERBOSE 允许写注释和空白，复杂正则更易读
PHONE = re.compile(r"""
    ^1          # 以 1 开头
    [3-9]       # 第二位 3-9
    \d{9}$      # 后面 9 位数字
""", re.VERBOSE)

多个标志用 | 组合：re.I | re.M。

07.常见坑

  1. match 只匹配开头：想在任意位置查找要用 search；想校验整串要用 fullmatch 或给模式加 ^...$。
  2. findall 遇到分组只返回分组内容：re.findall(r"(\d+)元", "5元 8元") 返回 ['5', '8']；有多个分组时返回元组列表。只想分组不想影响结果，用 (?:...)。
  3. 忘了用原始字符串："\bword\b" 中的 \b 是退格字符，正则永远匹配不上，应写 r"\bword\b"。
  4. 特殊字符没转义：匹配用户输入的字面文本时用 re.escape()，例如 re.escape("1+1=2") 得到 1\+1=2。
  5. $ 可以匹配末尾换行之前：re.match(r"\d+$", "123\n") 是能匹配成功的；严格校验时用 fullmatch 或 \Z。
  6. 灾难性回溯：类似 (a+)+$ 这样的嵌套量词，遇到不匹配的长字符串时回溯次数会指数级增长，导致 CPU 飙升（ReDoS）。避免嵌套量词、尽量写明确的字符集。
  7. 不要用正则解析 HTML/JSON：结构化数据用 html.parser、BeautifulSoup、json 等专门工具。

08.小结

  • 写正则一律用 r"..." 原始字符串。
  • match 从开头、search 找第一个、fullmatch 全匹配、findall 找全部、finditer 惰性找全部、sub 替换、split 切分。
  • 分组用 ()，命名分组 (?P<name>...)，不捕获用 (?:...)。
  • 量词默认贪婪，加 ? 变非贪婪。
  • 面试高频：match 与 search 的区别、贪婪与非贪婪、findall 与分组的关系。
