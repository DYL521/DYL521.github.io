一、标题层级与正文排版

1.1 长段落与中英混排节奏

在构建企业级 AI Agent 平台时，状态持久化（State Persistence） 与 工具调用隔离（Tool Sandboxing） 往往决定了系统的可靠性上限。相比直接把所有逻辑堆进单个 Prompt，采用显式状态机（如 LangGraph）能够将 Planning、Execution 和 Verification 拆解为可观测、可回放的独立节点。

行内样式混排测试：重点加粗文字、斜体强调、粗斜体、已废弃方案、核心高亮片段、async/await 行内代码、按键 Cmd + K、站内链接，以及主题扩展类：黄色标记 绿色标记 蓝色标记 红色标记 紫色标记、主题色关键强调、渐变标题文字。

状态徽标：默认 生产可用 Beta Breaking 实验性

1.1.1 四级标题与嵌套列表

  1. 第一阶段：需求拆解与原型验证
    • 明确核心 SLA 指标（P99 延迟 < 800ms）
    • 梳理外部工具鉴权边界与最小权限原则
    • 搭建最小可运行链路（MVP）
  2. 第二阶段：稳定性与可观测性建设
    • 接入 OpenTelemetry 全链路追踪
    • 补充降级策略与熔断阈值
      • 模型超时自动切换备用节点
      • 工具调用失败重试最多 2 次

2.4 定义列表

RAG（Retrieval-Augmented Generation）
检索增强生成，在推理前动态召回外部知识片段，显著降低模型幻觉。
MCP（Model Context Protocol）
面向 Agent 与工具/数据源的标准化上下文协议，统一发现与调用接口。

package pipeline

import (
	"context"
	"fmt"
	"time"
)

// RunWithTimeout executes a task with explicit deadline propagation and structured error wrapping.
func RunWithTimeout(ctx context.Context, d time.Duration, fn func(context.Context) error) error {
	ctx, cancel := context.WithTimeout(ctx, d)
	defer cancel()

	if err := fn(ctx); err != nil {
		return fmt.Errorf("pipeline execution failed after %s: %w", d, err)
	}
	return nil
}
