Java基础

Java 2024-11-24 · 更新于 2026-11-21 · 6 分钟阅读 · 1694 字

01.Java 简介

Java 是一门面向对象、静态类型、跨平台的编程语言。源代码先由 javac 编译成字节码（.class），再由 JVM 解释执行或 JIT 编译成机器码运行，因此可以"一次编译，到处运行"。

几个容易混淆的概念：

名称 说明
JVM Java 虚拟机，负责加载、执行字节码，管理内存与垃圾回收
JRE 运行环境 = JVM + 核心类库（JDK 11 起官方不再单独提供 JRE）
JDK 开发工具包 = JRE + 编译器 javac、jar、jshell、jcmd 等工具

当前长期支持（LTS）版本为 Java 17、Java 21、Java 25，新项目建议至少使用 Java 17。

java -version          # 查看版本
javac Hello.java       # 编译
java Hello             # 运行
java Hello.java        # JDK 11+ 可直接运行单个源文件

02.基本数据类型

Java 有 8 种基本类型，其余都是引用类型。

类型 字节 默认值 包装类
byte 1 0 Byte
short 2 0 Short
int 4 0 Integer
long 8 0L Long
float 4 0.0f Float
double 8 0.0d Double
char 2 ‘\u0000’ Character
boolean 未明确规定 false Boolean

2.1 自动装箱与缓存

Integer a = 127, b = 127;
System.out.println(a == b);       // true，-128~127 走 IntegerCache
Integer c = 128, d = 128;
System.out.println(c == d);       // false，超出缓存范围，是两个对象
System.out.println(c.equals(d));  // true

结论：包装类比较值一律用 equals。另外，包装类拆箱时如果为 null 会抛 NullPointerException。

2.2 浮点数精度

System.out.println(0.1 + 0.2);    // 0.30000000000000004
BigDecimal x = new BigDecimal("0.1");   // 用字符串构造，不要用 new BigDecimal(0.1)
BigDecimal y = new BigDecimal("0.2");
System.out.println(x.add(y));     // 0.3

金额计算使用 BigDecimal 或以"分"为单位的 long。比较 BigDecimal 大小用 compareTo，equals 会比较精度（1.0 与 1.00 不相等）。

03.面向对象

3.1 三大特性

  • 封装：隐藏内部实现，通过 private 字段 + 公开方法控制访问。
  • 继承：extends 复用父类代码，Java 类只支持单继承，接口可以多实现。
  • 多态：父类引用指向子类对象，运行时根据实际类型调用方法（动态绑定）。

3.2 访问修饰符

修饰符 本类 同包 子类 其他包
private ✓
默认（不写） ✓ ✓
protected ✓ ✓ ✓
public ✓ ✓ ✓ ✓

3.3 重载与重写

  • 重载（Overload）：同一个类中方法名相同、参数列表不同，与返回值无关，编译期决定。
  • 重写（Override）：子类重新实现父类方法，方法签名相同，访问权限不能更严格，抛出的受检异常不能更宽，运行期决定。

3.4 抽象类与接口

对比项 抽象类 接口
关键字 abstract class interface
继承 单继承 可多实现
成员变量 任意 只能是 public static final 常量
方法 可有构造器、普通方法 Java 8 起可有 default / static 方法，Java 9 起可有 private 方法
语义 “是什么”（is-a） “能做什么”（can-do）

04.String 相关

  • String 是不可变的（内部 final 数组，Java 9 起改为 byte[] + 编码标记，节省内存）。
  • 不可变带来的好处：线程安全、可以缓存 hashCode、可以放入字符串常量池复用。
  • 字符串拼接：循环中使用 StringBuilder（非线程安全，性能好）；StringBuffer 方法加了 synchronized，现在很少使用。
String s1 = "abc";
String s2 = "abc";
String s3 = new String("abc");
System.out.println(s1 == s2);           // true，同一个常量池对象
System.out.println(s1 == s3);           // false，s3 是堆上新对象
System.out.println(s1 == s3.intern());  // true

05.equals 与 hashCode

  • == 比较基本类型的值、引用类型的地址。
  • equals 默认等同 ==，String、包装类等对其进行了重写以比较内容。
  • 约定：重写 equals 必须同时重写 hashCode，否则对象放入 HashMap / HashSet 时会出现"相等的对象找不到"的问题。

Java 16 起可以使用 record 定义不可变数据类，编译器会自动生成构造器、访问器、equals、hashCode、toString：

public record User(Long id, String name) {}

06.异常体系

flowchart TD
    T[Throwable] --> E[Error]
    T --> X[Exception]
    X --> R[RuntimeException
非受检异常]
    X --> C[IOException / SQLException 等
受检异常]
    E --> O[OutOfMemoryError / StackOverflowError]
  • Error：JVM 层面的严重错误，程序一般无法处理。
  • 受检异常（Checked）：编译器强制要求 try-catch 或 throws。
  • 非受检异常（Unchecked）：RuntimeException 及其子类，如 NullPointerException、IllegalArgumentException。

资源释放推荐使用 try-with-resources（Java 7+），实现了 AutoCloseable 的资源会被自动关闭：

try (var reader = Files.newBufferedReader(Path.of("a.txt"))) {
    reader.lines().forEach(System.out::println);
} catch (IOException e) {
    throw new UncheckedIOException(e);
}

注意：finally 中不要写 return，它会覆盖 try 中的返回值并吞掉异常。

07.常用关键字

  • final：修饰类不可继承、修饰方法不可重写、修饰变量只能赋值一次（引用不可变，对象内容仍可变）。
  • static：属于类而非实例；静态方法中不能直接访问实例成员。
  • transient：序列化时忽略该字段。
  • volatile：保证可见性和禁止指令重排，但不保证复合操作的原子性。

08.值传递

Java 只有值传递。传递引用类型时，传递的是"引用的副本"：方法内修改对象的属性会影响外部，但让形参指向新对象不会影响外部变量。

static void change(StringBuilder sb) {
    sb.append("!");              // 影响外部
    sb = new StringBuilder("x"); // 不影响外部
}

09.现代 Java 常用语法（8 → 21）

// Lambda 与 Stream（Java 8）
List<String> names = users.stream()
        .filter(u -> u.age() > 18)
        .map(User::name)
        .toList();                     // Java 16+

// var 局部变量类型推断（Java 10）
var map = new HashMap<String, Integer>();

// 文本块（Java 15）
String json = """
        {"name": "dyl"}
        """;

// switch 表达式（Java 14）与模式匹配（Java 21）
String desc = switch (obj) {
    case Integer i when i > 0 -> "正整数";
    case String s -> "字符串:" + s;
    case null -> "null";
    default -> "其他";
};

// instanceof 模式匹配（Java 16）
if (obj instanceof String s && !s.isBlank()) {
    System.out.println(s.length());
}

此外还有 sealed 密封类（Java 17）限制继承范围，以及 Java 21 正式发布的虚拟线程 Thread.ofVirtual()。

10.常见坑

  1. 包装类用 == 比较，在缓存范围内"碰巧"正确，超出范围就出错。
  2. Arrays.asList() 返回的是固定长度列表，调用 add / remove 抛 UnsupportedOperationException；List.of() 返回的是完全不可变列表。
  3. 在 foreach 循环中直接 remove 集合元素会抛 ConcurrentModificationException，应使用 Iterator.remove() 或 removeIf。
  4. 整数溢出不会报错：Integer.MAX_VALUE + 1 变成负数，需要时用 Math.addExact。
  5. 三目运算符中混用包装类与基本类型可能触发自动拆箱导致 NPE。

小结

Java 基础的重点可以概括为：类型系统（8 种基本类型、装箱拆箱、浮点精度）、面向对象（封装继承多态、抽象类与接口、重载与重写）、核心类（String 不可变、equals/hashCode 约定）、异常体系和值传递。在此基础上掌握 Java 8 之后的新语法（Lambda、Stream、record、switch 模式匹配），就能应对日常开发和大部分基础面试题。
