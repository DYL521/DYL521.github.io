手把手刷数组算法

算法 2024-12-15 · 18 分钟阅读 · 5173 字
  • https://labuladong.online/algo/essential-technique/array-two-pointers-summary-2/

在处理数组和链表相关问题是，双指针的技巧是经常用到的，双指针主要分为两类：

  • 左右指针：两个指针相向而行或者背向而行；
  • 快慢指针：两个指针通向而行，一块 一慢；

数组和链表最大的区别是数组支持随机访问，所以左右指针（尤其是二分查找）在数组上用得更多；而链表上的双指针技巧见《手把手刷链表算法》。滑动窗口本质上也是快慢指针，单独整理在《滑动窗口算法核心代码模板》里，本篇不再展开。

一、快慢指针：原地修改数组

数组「原地删除」元素时，如果每删一个就把后面的元素整体前移，复杂度是 O(n2)O(n^2)O(n​2​​)。快慢指针的思路是：

  • fast 负责向前探路，遍历每一个元素；
  • slow 指向「结果数组」的下一个待写位置，nums[0..slow-1] 始终是已经处理好的答案；
  • 当 fast 遇到需要保留的元素，就写到 nums[slow]，然后 slow += 1。
# 快慢指针原地修改框架
def framework(nums):
    slow = 0
    for fast in range(len(nums)):
        if 需要保留(nums[fast]):
            nums[slow] = nums[fast]
            slow += 1
    return slow  # 结果数组的长度

26. 删除有序数组中的重复项

有序数组中重复元素一定相邻。slow 指向最后一个不重复元素，fast 发现新元素就写到 slow 的下一位。

class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        if not nums:
            return 0
        slow = 0
        for fast in range(1, len(nums)):
            if nums[fast] != nums[slow]:
                slow += 1
                nums[slow] = nums[fast]
        # nums[0..slow] 是去重结果，长度为 slow + 1
        return slow + 1

同样的逻辑放到链表上就是 83 题「删除排序链表中的重复元素」，只是把赋值换成改 next 指针。

27. 移除元素

注意和 26 题的细节差异：这里先赋值再 slow += 1，保证 nums[0..slow-1] 不含 val，最终长度就是 slow。

class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != val:
                nums[slow] = nums[fast]
                slow += 1
        return slow

283. 移动零

相当于先「移除所有 0」，再把 slow 之后的位置全部填 0。

class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow] = nums[fast]
                slow += 1
        for i in range(slow, len(nums)):
            nums[i] = 0

80. 删除有序数组中的重复项 II（每个元素最多保留两个）

推广到「最多保留 k 个」：当前元素只要和结果数组的倒数第 k 个元素不同，就可以保留。

class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        k = 2
        slow = 0
        for x in nums:
            if slow < k or nums[slow - k] != x:
                nums[slow] = x
                slow += 1
        return slow

二、左右指针

二分查找（704）

二分查找是最经典的左右指针，这里给出「搜索区间左闭右闭」的写法：

class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1   # 搜索区间 [left, right]
        while left <= right:             # 区间为空时才退出
            mid = left + (right - left) // 2
            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1
        return -1

坑：while 条件、right 初值、left/right 的更新三者必须和「搜索区间开闭」保持一致，最容易写错的就是这里。

167. 两数之和 II - 输入有序数组

数组有序，和偏大就让 right 左移，偏小就让 left 右移，类似二分。题目要求返回从 1 开始的下标。

class Solution:
    def twoSum(self, numbers: List[int], target: int) -> List[int]:
        left, right = 0, len(numbers) - 1
        while left < right:
            s = numbers[left] + numbers[right]
            if s == target:
                return [left + 1, right + 1]
            elif s < target:
                left += 1
            else:
                right -= 1
        return [-1, -1]

344. 反转字符串

class Solution:
    def reverseString(self, s: List[str]) -> None:
        left, right = 0, len(s) - 1
        while left < right:
            s[left], s[right] = s[right], s[left]
            left += 1
            right -= 1

5. 最长回文子串（中心扩散，背向而行）

回文串的难点在于长度可能是奇数也可能是偶数。以每个位置（或相邻两个位置）为中心，左右指针向两边扩散：

class Solution:
    def longestPalindrome(self, s: str) -> str:
        def palindrome(l: int, r: int) -> str:
            # 从 s[l] 和 s[r] 向两端扩散，返回最长回文串
            while l >= 0 and r < len(s) and s[l] == s[r]:
                l -= 1
                r += 1
            return s[l + 1:r]

        res = ""
        for i in range(len(s)):
            s1 = palindrome(i, i)       # 奇数长度，以 s[i] 为中心
            s2 = palindrome(i, i + 1)   # 偶数长度，以 s[i], s[i+1] 为中心
            res = max(res, s1, s2, key=len)
        return res

时间 O(n2)O(n^2)O(n​2​​)，空间 O(1)O(1)O(1)。

11. 盛最多水的容器

面积由较短的那根柱子决定。移动较高的一边，宽度变小、高度不会超过矮边，面积只会更小；所以每次移动较矮的一边。

class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        res = 0
        while left < right:
            res = max(res, min(height[left], height[right]) * (right - left))
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        return res

三、复杂度与易错点

题目 指针类型 时间 空间
26 / 27 / 283 / 80 快慢指针 O(n)O(n)O(n) O(1)O(1)O(1)
704 左右指针（二分） O(logn)O(\log n)O(logn) O(1)O(1)O(1)
167 / 344 / 11 左右指针（相向） O(n)O(n)O(n) O(1)O(1)O(1)
5 左右指针（背向） O(n2)O(n^2)O(n​2​​) O(1)O(1)O(1)
  • 26 与 27 的 slow 语义不同：一个指向「最后一个有效元素」，一个指向「下一个待写位置」，返回值分别是 slow + 1 和 slow，不要混用；
  • 左右指针的循环条件：相向而行一般写 left < right（两指针重合时没有意义），二分左闭右闭写 left <= right；
  • 原地修改题：题目只检查前 k 个元素，后面的残留值无所谓，不用额外清理（283 除外）；
  • Python 中不必担心 (left + right) // 2 溢出，但写成 left + (right - left) // 2 是跨语言的好习惯。

小结

  1. 「原地删除 / 去重 / 移动」类题目 → 快慢指针，slow 维护结果区间；
  2. 「有序数组找两个数 / 反转 / 二分」→ 相向的左右指针，利用有序性决定移动哪一边；
  3. 「回文串」→ 背向的左右指针，从中心向两边扩散，奇偶两种中心都要试；
  4. 「子数组 / 子串满足某条件」→ 滑动窗口（也是快慢指针），见滑动窗口模板一篇。
