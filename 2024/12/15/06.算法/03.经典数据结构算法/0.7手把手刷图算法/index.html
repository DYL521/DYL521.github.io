图可以看作是多叉树的延伸：树的节点只有子节点，图的节点有「邻居」，而且可能成环。所以图的遍历就是在多叉树遍历框架上加一个 visited 数组，防止在环上无限循环（多叉树框架见《二叉树的扩展延伸》）。

本篇覆盖：图的存储、DFS/BFS 遍历框架、环检测与拓扑排序、二分图判定、并查集、Dijkstra 最短路径。

一、图的存储

方式 结构 判断 u→v 是否相连 遍历 u 的邻居 空间 适用
邻接表 graph[u] = [v1, v2, ...] O(degu)O(\deg u)O(degu) O(degu)O(\deg u)O(degu) O(V+E)O(V+E)O(V+E) 稀疏图（大多数题目）
邻接矩阵 matrix[u][v] = True/权重 O(1)O(1)O(1) O(V)O(V)O(V) O(V2)O(V^2)O(V​2​​) 稠密图、需要频繁判断连边

题目一般给出边列表 edges = [[from, to], ...]，第一步通常是转成邻接表：

def build_graph(n, edges):
    graph = [[] for _ in range(n)]
    for u, v in edges:
        graph[u].append(v)      # 有向图；无向图再加 graph[v].append(u)
    return graph

二、遍历框架

DFS 框架

visited = [False] * n   # 记录被遍历过的节点，防止走回头路
on_path = [False] * n   # 记录当前递归栈上的节点（回溯时撤销），用于环检测

def traverse(graph, s):
    if visited[s]:
        return
    visited[s] = True
    on_path[s] = True       # 前序位置：进入节点
    for nxt in graph[s]:
        traverse(graph, nxt)
    on_path[s] = False      # 后序位置：离开节点

visited 和 on_path 的区别：visited 一旦置 True 就不再撤销，保证每个节点只访问一次；on_path 类似回溯中的「路径」，只表示当前这条 DFS 链路上的节点。有向图中，如果遇到一个 on_path 为 True 的节点，说明出现了环。

BFS 框架

from collections import deque

def bfs(graph, start):
    visited = [False] * len(graph)
    q = deque([start])
    visited[start] = True
    step = 0
    while q:
        for _ in range(len(q)):         # 按层遍历，step 即为层数（无权图的最短距离）
            cur = q.popleft()
            for nxt in graph[cur]:
                if not visited[nxt]:
                    visited[nxt] = True  # 入队时标记，避免同一节点重复入队
                    q.append(nxt)
        step += 1

三、代表题目

797. 所有可能的路径

给一个有向无环图，求从 0 到 n-1 的所有路径。因为无环，不需要 visited，直接用回溯框架遍历：

class Solution:
    def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:
        res, path = [], []
        target = len(graph) - 1

        def traverse(s):
            path.append(s)
            if s == target:
                res.append(path[:])     # 注意要拷贝
            else:
                for nxt in graph[s]:
                    traverse(nxt)
            path.pop()

        traverse(0)
        return res

207. 课程表（有向图环检测）

课程依赖关系 [a, b] 表示「学 a 之前要先学 b」，建图为 b → a。能修完所有课 ⇔ 图中无环。用上面的 DFS 框架 + on_path：

class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        graph = [[] for _ in range(numCourses)]
        for a, b in prerequisites:
            graph[b].append(a)
        visited = [False] * numCourses
        on_path = [False] * numCourses
        self.has_cycle = False

        def traverse(s):
            if on_path[s]:
                self.has_cycle = True   # 回到了当前路径上的节点 → 有环
            if visited[s] or self.has_cycle:
                return
            visited[s] = True
            on_path[s] = True
            for nxt in graph[s]:
                traverse(nxt)
            on_path[s] = False

        for i in range(numCourses):     # 图可能不连通，每个节点都要作为起点试一次
            traverse(i)
        return not self.has_cycle

坑：判断 on_path 必须在判断 visited 之前，因为在环上的节点一定已经被 visited 了。另外 Python 默认递归深度 1000，节点很多时可以改用下面的 BFS 写法。

210. 课程表 II（拓扑排序，Kahn 算法）

BFS 版拓扑排序：先把入度为 0 的节点入队，每出队一个节点，就把它指向的节点入度减 1，减到 0 再入队。出队顺序就是拓扑序；如果最后出队的节点数不足 n，说明有环。

from collections import deque

class Solution:
    def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
        graph = [[] for _ in range(numCourses)]
        indegree = [0] * numCourses
        for a, b in prerequisites:
            graph[b].append(a)
            indegree[a] += 1
        q = deque(i for i in range(numCourses) if indegree[i] == 0)
        order = []
        while q:
            cur = q.popleft()
            order.append(cur)
            for nxt in graph[cur]:
                indegree[nxt] -= 1
                if indegree[nxt] == 0:
                    q.append(nxt)
        return order if len(order) == numCourses else []

时间 O(V+E)O(V+E)O(V+E)。DFS 版本的拓扑序是后序遍历结果的逆序，也可以记住。

785. 判断二分图

二分图：能把节点染成两种颜色，使每条边两端颜色不同。遍历图的同时染色，遇到已染色的邻居就检查颜色是否冲突：

from collections import deque

class Solution:
    def isBipartite(self, graph: List[List[int]]) -> bool:
        n = len(graph)
        color = [-1] * n            # -1 表示未染色，0/1 两种颜色
        for start in range(n):      # 图可能不连通
            if color[start] != -1:
                continue
            color[start] = 0
            q = deque([start])
            while q:
                cur = q.popleft()
                for nxt in graph[cur]:
                    if color[nxt] == -1:
                        color[nxt] = 1 - color[cur]
                        q.append(nxt)
                    elif color[nxt] == color[cur]:
                        return False
        return True

547. 省份数量（并查集 Union-Find）

并查集专门处理无向图的动态连通性：合并两个连通分量、判断两点是否连通，均摊接近 O(1)O(1)O(1)。

class UF:
    def __init__(self, n):
        self.parent = list(range(n))
        self.count = n                      # 连通分量个数

    def find(self, x):
        # 路径压缩：让 x 直接指向根
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, p, q):
        rp, rq = self.find(p), self.find(q)
        if rp == rq:
            return
        self.parent[rp] = rq
        self.count -= 1

    def connected(self, p, q):
        return self.find(p) == self.find(q)


class Solution:
    def findCircleNum(self, isConnected: List[List[int]]) -> int:
        n = len(isConnected)
        uf = UF(n)
        for i in range(n):
            for j in range(i + 1, n):
                if isConnected[i][j]:
                    uf.union(i, j)
        return uf.count

这里用的是「隔代压缩」（parent[x] = parent[parent[x]]），写法短且不需要递归；再配合按秩合并可以严格保证 O(α(n))O(\alpha(n))O(α(n))。

743. 网络延迟时间（Dijkstra）

求从 k 出发到所有节点的最短路径中的最大值。边权非负，用 Dijkstra + 最小堆：每次弹出当前距离最小的节点，它的最短距离就确定了，再用它去「松弛」邻居。

import heapq

class Solution:
    def networkDelayTime(self, times: List[List[int]], n: int, k: int) -> int:
        graph = [[] for _ in range(n + 1)]      # 节点编号 1..n
        for u, v, w in times:
            graph[u].append((v, w))
        dist = [float('inf')] * (n + 1)
        dist[k] = 0
        heap = [(0, k)]
        while heap:
            d, u = heapq.heappop(heap)
            if d > dist[u]:                     # 过期的堆元素，跳过
                continue
            for v, w in graph[u]:
                if d + w < dist[v]:
                    dist[v] = d + w
                    heapq.heappush(heap, (dist[v], v))
        ans = max(dist[1:])
        return ans if ans < float('inf') else -1

时间 O(ElogE)O(E \log E)O(ElogE)。坑：Dijkstra 不能处理负权边（负权用 Bellman-Ford / SPFA）；d > dist[u] 这一行的剪枝不能省，否则同一节点会被重复展开。

四、复杂度汇总

算法 时间 典型题

环检测 / 拓扑排序 O(V+E)O(V+E)O(V+E) 207、210
二分图判定 O(V+E)O(V+E)O(V+E) 785、886
并查集 每次操作均摊 O(α(n))O(\alpha(n))O(α(n)) 547、990
Dijkstra（堆优化） O(ElogE)O(E\log E)O(ElogE) 743、1631

小结

  1. 图 = 可能有环的多叉树，遍历时用 visited 防止重复访问；
  2. 有向图环检测用 on_path（DFS）或入度表（BFS/Kahn），后者顺便得到拓扑序；
  3. 二分图判定就是「遍历 + 双色染色」，注意图可能不连通；
  4. 无向图连通性问题优先想并查集；
  5. 非负权单源最短路用 Dijkstra，无权图最短路直接 BFS 按层计数即可。
