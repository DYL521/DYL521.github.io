二叉树的扩展延伸

算法 2024-12-15 · 17 分钟阅读 · 5025 字

《手把手刷二叉树算法》里总结了两种思维模式：遍历（traverse + 外部变量）和分解问题（定义递归函数，利用子树返回值），以及前/中/后序位置的含义。本篇在此基础上延伸几类更进阶的题型：构造与序列化、后序位置的妙用、最近公共祖先、二叉搜索树（BST），最后再看二叉树框架是如何「延伸」成回溯、动态规划和图算法的。

节点定义沿用 LeetCode：

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

一、构造类问题：分解问题的思维

二叉树的构造问题一般都用「分解问题」的思路：构造整棵树 = 根节点 + 构造左子树 + 构造右子树。关键是在遍历结果中找到根节点，并划分出左右子树对应的区间。

105. 从前序与中序遍历序列构造二叉树

  • 前序的第一个元素是根；
  • 在中序中找到根的位置 idx，左边是左子树、右边是右子树，左子树大小 left_size = idx - in_lo；
  • 据此切分前序区间，递归构造。
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        # 值 -> 中序下标，避免每次线性查找（题目保证无重复值）
        index = {v: i for i, v in enumerate(inorder)}

        def build(pre_lo, pre_hi, in_lo, in_hi):
            if pre_lo > pre_hi:
                return None
            root_val = preorder[pre_lo]
            idx = index[root_val]
            left_size = idx - in_lo
            root = TreeNode(root_val)
            root.left = build(pre_lo + 1, pre_lo + left_size, in_lo, idx - 1)
            root.right = build(pre_lo + left_size + 1, pre_hi, idx + 1, in_hi)
            return root

        return build(0, len(preorder) - 1, 0, len(inorder) - 1)

时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。坑：索引区间一定要画图算清楚，最常见的错误是左子树前序区间写成 pre_lo + 1 .. idx（混用了中序下标）。同理可以做 106（中序 + 后序，根在后序末尾）。

297. 二叉树的序列化与反序列化

用前序遍历 + 空指针占位符 # 序列化。因为记录了空指针，单靠前序就能唯一确定一棵树：反序列化时第一个元素是根，然后递归地依次消费列表构造左、右子树。

class Codec:
    SEP, NULL = ",", "#"

    def serialize(self, root):
        res = []

        def traverse(node):
            if node is None:
                res.append(self.NULL)
                return
            res.append(str(node.val))      # 前序位置
            traverse(node.left)
            traverse(node.right)

        traverse(root)
        return self.SEP.join(res)

    def deserialize(self, data):
        nodes = iter(data.split(self.SEP))

        def build():
            val = next(nodes)
            if val == self.NULL:
                return None
            root = TreeNode(int(val))
            root.left = build()
            root.right = build()
            return root

        return build()

中序遍历无法反序列化：拿不到根节点的位置；后序遍历可以，从列表末尾往前消费，并且先构造右子树再构造左子树。

二、后序位置的妙用

前序位置只能拿到从父节点传下来的信息，后序位置还能拿到子树通过返回值传上来的信息。凡是题目和「子树」有关，大概率要在后序位置写代码。

543. 二叉树的直径

直径 = 某个节点的「左子树最大深度 + 右子树最大深度」的最大值。在计算最大深度的后序位置顺便更新答案：

class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        self.res = 0

        def max_depth(node):
            if node is None:
                return 0
            left = max_depth(node.left)
            right = max_depth(node.right)
            # 后序位置：已知左右子树深度，顺便计算经过 node 的直径
            self.res = max(self.res, left + right)
            return 1 + max(left, right)

        max_depth(root)
        return self.res

如果在前序位置对每个节点都调用一次 max_depth，复杂度是 O(n2)O(n^2)O(n​2​​)；利用后序返回值只需 O(n)O(n)O(n)。

652. 寻找重复的子树

要知道「以我为根的子树长什么样」，只能在后序位置把子树序列化成字符串，再用哈希表计数：

class Solution:
    def findDuplicateSubtrees(self, root: Optional[TreeNode]) -> List[Optional[TreeNode]]:
        memo = collections.defaultdict(int)
        res = []

        def serialize(node):
            if node is None:
                return "#"
            left = serialize(node.left)
            right = serialize(node.right)
            s = f"{left},{right},{node.val}"   # 后序序列化
            memo[s] += 1
            if memo[s] == 2:                    # 只在第二次出现时加入，避免重复
                res.append(node)
            return s

        serialize(root)
        return res

这种写法字符串拼接的总长度最坏为 O(n2)O(n^2)O(n​2​​)，面试中说明即可；优化思路是给每种子树结构分配一个整数 id。

三、最近公共祖先（LCA）

236. 二叉树的最近公共祖先

定义 find(root, p, q)：在以 root 为根的树中寻找 p 或 q，找到就返回，否则返回 None。

  • 前序位置：如果 root 本身就是 p 或 q，直接返回 root（另一个节点要么在它下面，要么根本不在这棵子树里，答案都是 root）；
  • 后序位置：如果左右子树各找到一个，说明 root 就是 LCA；否则返回非空的那一边。
class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        if root is None or root is p or root is q:
            return root
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        if left and right:
            return root
        return left if left else right

时间 O(n)O(n)O(n)。如果是 BST（235 题），可以利用大小关系：p、q 都比 root 小就去左子树，都比 root 大就去右子树，否则 root 就是答案，时间 O(h)O(h)O(h)。

四、二叉搜索树（BST）

BST 的核心特性是「左小右大」，以及中序遍历结果有序。几乎所有 BST 题目都围绕这两点。

98. 验证二叉搜索树

坑：只比较节点和它的左右孩子是不够的，必须保证整棵左子树都小于 root。做法是把上下界作为参数往下传：

class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def check(node, lo, hi):
            # 要求 lo.val < node.val < hi.val
            if node is None:
                return True
            if lo is not None and node.val <= lo.val:
                return False
            if hi is not None and node.val >= hi.val:
                return False
            return check(node.left, lo, node) and check(node.right, node, hi)

        return check(root, None, None)

230. 二叉搜索树中第 K 小的元素

中序遍历有序，数到第 k 个即可（遍历思维）：

class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        stack, node = [], root
        while stack or node:
            while node:                 # 一路向左
                stack.append(node)
                node = node.left
            node = stack.pop()          # 中序位置
            k -= 1
            if k == 0:
                return node.val
            node = node.right
        return -1

用显式栈的迭代写法可以在找到答案后立即停止，时间 O(h+k)O(h + k)O(h+k)。

450. 删除二叉搜索树中的节点

找到目标节点后分三种情况：

  1. 叶子节点：直接删除；
  2. 只有一个孩子：让孩子顶替自己；
  3. 有两个孩子：找到右子树的最小节点（后继），用它的值替换自己，再到右子树中删除这个后继。
class Solution:
    def deleteNode(self, root: Optional[TreeNode], key: int) -> Optional[TreeNode]:
        if root is None:
            return None
        if key < root.val:
            root.left = self.deleteNode(root.left, key)
        elif key > root.val:
            root.right = self.deleteNode(root.right, key)
        else:
            if root.left is None:       # 情况 1、2
                return root.right
            if root.right is None:
                return root.left
            succ = root.right           # 情况 3：找右子树最小节点
            while succ.left:
                succ = succ.left
            root.val = succ.val
            root.right = self.deleteNode(root.right, succ.val)
        return root

时间 O(h)O(h)O(h)。BST 的增删改查都要把递归结果接回父节点（root.left = ...），这是和普通二叉树遍历最大的区别。

五、二叉树框架的延伸

二叉树之所以重要，是因为很多算法本质上都是在一棵「树」上做遍历：

算法 对应的树 对应的思维
回溯（全排列、子集、N 皇后） 多叉决策树 遍历：在前序位置「做选择」，后序位置「撤销选择」
动态规划（斐波那契、零钱兑换） 递归树 分解问题：子问题的答案推出原问题，用备忘录剪掉重复子树
快速排序 / 归并排序 递归树 前序 / 后序位置（见《手把手刷二叉树算法》）
DFS / BFS 图遍历 可能有环的「多叉树」 多叉树遍历 + visited 数组防止走回头路（见《手把手刷图算法》）

例如回溯框架就是多叉树遍历框架加上「选择 / 撤销」：

def backtrack(path, choices):
    if 满足结束条件:
        res.append(path[:])
        return
    for c in choices:
        path.append(c)          # 前序位置：做选择
        backtrack(path, choices)
        path.pop()              # 后序位置：撤销选择

小结

  1. 构造题用分解思维，核心是找根、算左子树大小、切分区间；
  2. 序列化用前序 + 空指针占位，反序列化按同样顺序消费；
  3. 和子树相关的信息（深度、结构、是否包含某节点）都在后序位置处理，往往能把 O(n2)O(n^2)O(n​2​​) 降到 O(n)O(n)O(n)；
  4. BST 抓住「左小右大」和「中序有序」，修改操作记得把递归结果接回去；
  5. 回溯、动态规划、图遍历都是二叉树遍历框架的延伸，把二叉树练熟，其他递归算法会轻松很多。
