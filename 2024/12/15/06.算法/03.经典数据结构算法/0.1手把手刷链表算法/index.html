手把手刷链表算法

算法 2024-12-15 · 24 分钟阅读 · 7079 字
  • https://labuladong.online/algo/essential-technique/linked-list-skills-summary/

链表题目看起来花样很多，但核心技巧只有三个：虚拟头节点（dummy）、双指针（快慢指针 / 两条链表各一个指针）、递归/迭代反转。本篇把这几类技巧和代表题整理在一起，数组上的双指针见《手把手刷数组算法》，链表在 LRU 中的应用见《手撸LRU算法》。

下面所有代码都基于 LeetCode 的链表节点定义：

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

一、虚拟头节点：合并与分解链表

什么时候用 dummy？ 当你需要创造一条新链表（合并、分解、删除节点后返回新头）时，头节点可能会变化，用一个 dummy 占位可以避免对「空链表 / 头节点」做特殊判断，最后返回 dummy.next 即可。

21. 合并两个有序链表

思路：两个指针 p1、p2 分别在两条链表上前进，每次把较小的节点接到结果链表尾部，类似「拉拉链」。

class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(-1)
        p, p1, p2 = dummy, list1, list2
        while p1 and p2:
            if p1.val <= p2.val:
                p.next = p1
                p1 = p1.next
            else:
                p.next = p2
                p2 = p2.next
            p = p.next
        # 剩下的那条直接接上
        p.next = p1 if p1 else p2
        return dummy.next

时间 O(m+n)O(m+n)O(m+n)，空间 O(1)O(1)O(1)。

86. 分隔链表

把小于 x 的节点放左边，其余放右边，保持相对顺序。思路是「分解」：用两个 dummy 分别收集两类节点，最后拼接。

class Solution:
    def partition(self, head: Optional[ListNode], x: int) -> Optional[ListNode]:
        dummy1, dummy2 = ListNode(-1), ListNode(-1)
        p1, p2, p = dummy1, dummy2, head
        while p:
            if p.val < x:
                p1.next = p
                p1 = p1.next
            else:
                p2.next = p
                p2 = p2.next
            # 断开原链表的 next，避免成环
            nxt = p.next
            p.next = None
            p = nxt
        p1.next = dummy2.next
        return dummy1.next

坑：一定要断开 p.next，否则大链表的尾节点可能仍然指向某个小节点，结果成环。

23. 合并 K 个升序链表

合并两条链表时每次比较 2 个节点，合并 k 条就需要快速拿到 k 个节点里的最小值 —— 最小堆。

import heapq

class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        dummy = ListNode(-1)
        p = dummy
        heap = []
        for i, head in enumerate(lists):
            if head:
                # 加入下标 i 作为第二关键字，避免 val 相同时比较 ListNode 报错
                heapq.heappush(heap, (head.val, i, head))
        while heap:
            _, i, node = heapq.heappop(heap)
            p.next = node
            p = p.next
            if node.next:
                heapq.heappush(heap, (node.next.val, i, node.next))
        return dummy.next

设节点总数为 N，堆大小最多 k，时间 O(Nlogk)O(N \log k)O(Nlogk)，空间 O(k)O(k)O(k)。

二、快慢指针

19. 删除链表的倒数第 N 个结点

找倒数第 k 个节点：让 p1 先走 k 步，然后 p1、p2 同时走，p1 走到末尾（None）时，p2 正好在倒数第 k 个节点。要删除倒数第 n 个，就要找到倒数第 n+1 个（它的前驱）。

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(-1, head)

        def find_from_end(start, k):
            p1 = p2 = start
            for _ in range(k):
                p1 = p1.next
            while p1:
                p1 = p1.next
                p2 = p2.next
            return p2

        # 从 dummy 出发找倒数第 n+1 个节点
        prev = find_from_end(dummy, n + 1)
        prev.next = prev.next.next
        return dummy.next

坑：必须从 dummy 开始找。如果要删的是头节点（n 等于链表长度），倒数第 n+1 个节点就是 dummy，不用 dummy 会空指针。

876. 链表的中间结点

慢指针一次走一步，快指针一次走两步，快指针到达末尾时慢指针就在中点。节点数为偶数时返回的是靠后的那个中点。

class Solution:
    def middleNode(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        return slow

141 / 142. 环形链表

  • 判断有环：快慢指针若相遇则有环（141）；
  • 找环起点（142）：相遇后，把其中一个指针放回 head，两者都每次走一步，再次相遇处就是环起点。

原理：设相遇时慢指针走了 k 步，快指针走了 2k 步，多走的 k 步恰好是环长的整数倍。设环起点到相遇点距离为 m，那么从 head 到环起点的距离为 k-m，从相遇点继续走 k-m 步也恰好回到环起点。

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:
                break
        else:
            return None  # fast 走到尽头，无环
        slow = head
        while slow is not fast:
            slow = slow.next
            fast = fast.next
        return slow

160. 相交链表

两条链表长度不同，无法同时到达交点。技巧：p1 走完 A 后接着走 B，p2 走完 B 后接着走 A，这样两者走过的总长度都是 lenA + lenB，会同时到达交点；若不相交，会同时到达 None。

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        p1, p2 = headA, headB
        while p1 is not p2:
            p1 = p1.next if p1 else headB
            p2 = p2.next if p2 else headA
        return p1

三、反转链表

206. 反转链表

迭代写法：三个指针 pre / cur / nxt，逐个把 cur.next 指回前驱。

class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        pre, cur = None, head
        while cur:
            nxt = cur.next
            cur.next = pre
            pre, cur = cur, nxt
        return pre

递归写法体现了「分解问题」的思维（见《手把手刷二叉树算法》的核心纲领）：reverseList(head) 的定义是反转以 head 为头的链表并返回新头。

class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if head is None or head.next is None:
            return head
        last = self.reverseList(head.next)  # 反转 head 之后的部分
        head.next.next = head               # 后继节点指回自己
        head.next = None
        return last

递归写法空间是 O(n)O(n)O(n) 的栈，链表很长时可能爆栈，工程上推荐迭代。

92. 反转链表 II

反转区间 [left, right]。用 dummy 找到 left 的前驱 pre，然后头插法：把 cur 后面的节点依次摘下来插到 pre 后面，执行 right - left 次。

class Solution:
    def reverseBetween(self, head: Optional[ListNode], left: int, right: int) -> Optional[ListNode]:
        dummy = ListNode(-1, head)
        pre = dummy
        for _ in range(left - 1):
            pre = pre.next
        cur = pre.next
        for _ in range(right - left):
            nxt = cur.next
            cur.next = nxt.next
            nxt.next = pre.next
            pre.next = nxt
        return dummy.next

25. K 个一组翻转链表

先检查剩余节点是否够 k 个，够的话反转 [a, b) 区间，然后递归处理后面的部分并接上。

class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        a = b = head
        for _ in range(k):
            if b is None:
                return head  # 不足 k 个，保持原样
            b = b.next
        # 反转 [a, b)
        pre, cur = None, a
        while cur is not b:
            nxt = cur.next
            cur.next = pre
            pre, cur = cur, nxt
        # 反转后 a 变成这一组的尾巴，接上后面递归的结果
        a.next = self.reverseKGroup(b, k)
        return pre

时间 O(n)O(n)O(n)，递归深度 O(n/k)O(n/k)O(n/k)。

四、复杂度与常见坑

题目 技巧 时间 空间
21 / 86 dummy + 双指针 O(n)O(n)O(n) O(1)O(1)O(1)
23 dummy + 最小堆 O(Nlogk)O(N\log k)O(Nlogk) O(k)O(k)O(k)
19 / 876 / 141 / 142 快慢指针 O(n)O(n)O(n) O(1)O(1)O(1)
160 双指针拼接 O(m+n)O(m+n)O(m+n) O(1)O(1)O(1)
206 / 92 / 25 反转 O(n)O(n)O(n) 迭代 O(1)O(1)O(1)
  • 改指针前先保存 next：nxt = cur.next 永远写在修改 cur.next 之前；
  • 断链防环：把原链表节点挂到新链表时，注意旧的 next 是否需要置 None（86 题）；
  • 循环条件：快慢指针写 while fast and fast.next，否则 fast.next.next 会空指针；
  • Python 的 is 与 ==：比较节点身份用 is，ListNode 未定义 __eq__，== 虽然也是比较身份，但语义上 is 更清晰；
  • 堆中放元组时加唯一序号：值相同时 Python 会继续比较 ListNode 而抛 TypeError。

小结

  1. 需要构造新链表 → 先想 dummy；
  2. 涉及「倒数第 k 个 / 中点 / 环 / 相交」→ 想 双指针，关键是让两个指针「步数差」或「总路程」满足某种关系；
  3. 反转类 → 熟练掌握 206 的迭代模板，92、25 都是在它的基础上划定区间；
  4. 写完后用「空链表、单节点、操作头节点、操作尾节点」四种边界手动走一遍。
