01.Pandas是什么

Pandas 是 Python 中最常用的数据分析库，名字来源于 “Panel Data”（面板数据）。它提供了两种核心数据结构：

  • Series：带索引的一维数组，可以理解为“一列数据”。
  • DataFrame：带行索引和列名的二维表格，可以理解为“一张 Excel 表”或“一张数据库表”。

用 Pandas 可以很方便地完成：读取 CSV/Excel/SQL/JSON 数据、清洗缺失值和重复值、筛选、排序、分组聚合、合并表格、时间序列处理，并配合 Matplotlib 等库做可视化。

它和其他库的关系：

  • NumPy：Pandas 的底层数据大多存放在 NumPy 数组中，向量化运算的思路也一样。
  • Matplotlib / Seaborn：负责画图，DataFrame 自带的 .plot() 就是基于 Matplotlib 的。
  • scikit-learn：机器学习库，通常先用 Pandas 处理好特征再交给它。

03.先认识 Series

import pandas as pd

s = pd.Series([90, 85, 77], index=["张三", "李四", "王五"], name="成绩")
print(s)
# 张三    90
# 李四    85
# 王五    77
# Name: 成绩, dtype: int64

print(s.index)       # Index(['张三', '李四', '王五'], dtype='object')
print(s.values)      # [90 85 77]
print(s["李四"])      # 85，按标签取值
print(s.iloc[0])     # 90，按位置取值
print(s[s > 80])     # 布尔筛选
print(s.mean())      # 84.0

也可以直接用字典创建：pd.Series({"a": 1, "b": 2})，字典的键会成为索引。

04.再认识 DataFrame

import pandas as pd

df = pd.DataFrame({
    "name": ["张三", "李四", "王五", "赵六"],
    "age": [23, 31, 27, 35],
    "city": ["北京", "上海", "北京", "深圳"],
    "salary": [12000, 18000, 15000, None],
})
print(df)
#   name  age city   salary
# 0   张三   23   北京  12000.0
# 1   李四   31   上海  18000.0
# 2   王五   27   北京  15000.0
# 3   赵六   35   深圳      NaN

注意 salary 列中有 None，Pandas 会把它表示成缺失值 NaN，整列也因此变成了浮点类型。

4.1 查看数据的基本信息

df.shape          # (4, 4)  行数、列数
df.columns        # 列名
df.index          # 行索引 RangeIndex(start=0, stop=4, step=1)
df.dtypes         # 每列的数据类型
df.head(2)        # 前 2 行（默认 5 行）
df.tail(2)        # 后 2 行
df.info()         # 列名、非空数量、类型、内存占用
df.describe()     # 数值列的统计摘要：count、mean、std、min、四分位数、max
df["city"].value_counts()   # 每个城市出现的次数

拿到一份新数据时，先跑一遍 shape、head()、info()、describe()，基本就能了解数据的全貌。

4.2 选择数据

df["name"]                 # 取一列，返回 Series
df[["name", "age"]]        # 取多列，返回 DataFrame

df.loc[0]                  # 按【标签】取一行
df.loc[0:2, ["name", "age"]]   # 标签切片，包含结束位置 2
df.iloc[0:2, 0:2]          # 按【位置】切片，不包含结束位置 2

df[df["age"] > 25]                              # 条件筛选
df[(df["age"] > 25) & (df["city"] == "北京")]   # 多条件用 & | ~，每个条件加括号
df.query("age > 25 and city == '北京'")          # 等价的 query 写法

4.3 新增列与简单计算

df["salary_k"] = df["salary"] / 1000          # 向量化运算，整列一起算
df["is_senior"] = df["age"] >= 30
df["salary"] = df["salary"].fillna(0)         # 填充缺失值
print(df.groupby("city")["salary"].mean())     # 按城市分组求平均工资

05.读写文件

df = pd.read_csv("data.csv")                    # 读 CSV

06.学习 Pandas 前要建立的几个观念

  1. 向量化优先，少写 for 循环：df["a"] * 2 这种整列运算由底层 C 代码完成，比用 for 循环或 iterrows() 逐行处理快得多。
  2. 索引（index）很重要：Series/DataFrame 之间做运算时会按索引对齐，而不是按位置。索引对不上的地方会得到 NaN。
  3. 大多数方法返回新对象：df.dropna()、df.sort_values("age") 默认不修改原 DataFrame，需要重新赋值：df = df.dropna()。不推荐使用 inplace=True。
  4. 分清 loc 和 iloc：loc 按标签、切片包含右端点；iloc 按位置、切片不包含右端点。
  5. 注意数据类型：从 CSV 读入的数字可能被识别为字符串（object），日期需要用 pd.to_datetime() 转换，计算前先看 df.dtypes。

07.常见坑

  1. 链式赋值：df[df["age"] > 30]["salary"] = 0 很可能修改的是一个临时副本，原数据不变，并触发 SettingWithCopyWarning。应该一步到位地用 loc：
df.loc[df["age"] > 30, "salary"] = 0
  1. Copy-on-Write：Copy-on-Write（写时复制）在 pandas 2.x 中是可选项，可以通过 pd.options.mode.copy_on_write = True 开启；从 pandas 3.0 起它成为默认行为。开启后，从一个 DataFrame 派生出来的对象都表现得像副本，修改它不会影响原数据，链式赋值将不再生效。养成“用 loc 一步赋值”的习惯，两种模式下都不会出错。
  2. 多条件筛选用 and/or：df[df.age > 25 and df.city == "北京"] 会报 ValueError: The truth value of a Series is ambiguous，要用 &、| 并给每个条件加括号。
  3. 整数列出现缺失值会变成浮点：如上面的 salary 列。需要保留整数可以使用可空整数类型 df["col"].astype("Int64")。
  4. df.col 属性访问的局限：列名和方法重名（如 count）、含空格或中文特殊字符时不能用属性方式访问，统一用 df["col"] 更稳妥。

08.小结

  • Pandas 的两大核心结构：一维的 Series 和二维的 DataFrame，都由“数据 + 索引”组成。
  • 拿到数据先用 head()、info()、describe() 了解全貌。
  • 选择数据用 []、loc（标签）和 iloc（位置），修改数据用 loc 一步完成。
  • 牢记向量化、索引对齐、方法默认返回新对象这三个观念，后续章节会在此基础上逐步展开数据清洗、分组聚合、合并与时间序列等内容。
