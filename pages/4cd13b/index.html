01.树

​ 二叉树、满二叉树、完全二叉树、平衡二叉树
​ B-tree/B+tree

一、概念速记

名称 定义 面试要点
二叉树 每个节点最多两个子节点 第 i 层最多 2i−12^{i-1}2​i−1​​ 个节点；n0=n2+1n_0 = n_2 + 1n​0​​=n​2​​+1（叶子数 = 度为 2 的节点数 + 1）
满二叉树 每层都是满的 深度为 h 时共 2h−12^h - 12​h​​−1 个节点
完全二叉树 除最后一层外都满，最后一层节点靠左连续 可以用数组存储：下标从 0 开始时，i 的左右孩子是 2i+12i+12i+1、2i+22i+22i+2，父节点是 (i−1)//2(i-1)//2(i−1)//2；堆就是完全二叉树
二叉搜索树 BST 左子树 < 根 < 右子树 中序遍历有序；最坏退化成链表，O(n)O(n)O(n)
平衡二叉树（AVL） 任意节点左右子树高度差 ≤ 1 严格平衡，查找快，插入删除旋转较多
红黑树 近似平衡，最长路径 ≤ 2 倍最短路径 旋转少，写性能稳定；TreeMap、HashMap 树化、std::map（详见数据结构分类下的《红黑树》）
B 树 多路平衡搜索树，节点内存多个 key，所有节点都存数据 矮胖，减少磁盘 IO
B+ 树 只有叶子节点存数据，非叶子只存索引；叶子之间用链表相连 MySQL InnoDB 索引结构

二、高频问答

Q1：为什么 MySQL 索引用 B+ 树，而不用 B 树、红黑树或哈希？

  • 红黑树 / AVL 是二叉的，千万级数据树高二十多层，每层一次磁盘 IO，太慢；B+ 树一个节点就是一页（InnoDB 默认 16KB），能放上千个 key，三层就能存千万级数据。
  • 相比 B 树：B+ 树非叶子节点不存数据，一页能放更多 key，树更矮；所有查询都要走到叶子，查询性能稳定；叶子节点有链表，范围查询和排序只需顺序扫描。
  • 相比哈希：哈希只支持等值查询，不支持范围查询、排序和最左前缀匹配。

Q2：红黑树和 AVL 树的区别？

AVL 严格平衡（高度差 ≤ 1），查找稍快，但插入删除可能需要多次旋转；红黑树只要求近似平衡，插入最多 2 次旋转、删除最多 3 次，适合增删频繁的场景。两者的增删查都是 O(logn)O(\log n)O(logn)。

Q3：Java 8 HashMap 为什么在链表长度达到 8 时转红黑树？

链表过长时查找退化为 O(n)O(n)O(n)，树化后为 O(logn)O(\log n)O(logn)。阈值 8 是按泊松分布算出来的，哈希均匀时几乎不会出现；且数组长度小于 64 时会优先扩容；节点数降到 6 时退化回链表，两个阈值不同是为了避免频繁来回转换。

Q4：只给前序和后序遍历，能唯一确定一棵二叉树吗？

一般不能。前序 + 中序、后序 + 中序可以唯一确定（节点值不重复时），因为中序能划分出左右子树；前序 + 后序无法区分「只有一个孩子时是左孩子还是右孩子」。

Q5：堆和 BST 的区别？

堆只保证父节点比子节点大（或小），是完全二叉树，适合求最值（Top K、优先队列），建堆 O(n)O(n)O(n)、插入删除 O(logn)O(\log n)O(logn)；BST 保证左小右大，中序有序，适合查找和范围查询。

1. 前中后序的非递归遍历（94 / 144 / 145）

面试官经常要求写迭代版。统一用一个栈 + 指针：一路向左压栈，弹出时就是中序位置；后序可以用「根 → 右 → 左」的前序结果反转得到。

def preorder(root):
    res, stack = [], [root] if root else []
    while stack:
        node = stack.pop()
        res.append(node.val)
        if node.right:              # 先压右，后压左，出栈时才是先左后右
            stack.append(node.right)
        if node.left:
            stack.append(node.left)
    return res


def inorder(root):
    res, stack, node = [], [], root
    while stack or node:
        while node:
            stack.append(node)
            node = node.left
        node = stack.pop()
        res.append(node.val)
        node = node.right
    return res


def postorder(root):
    res, stack = [], [root] if root else []
    while stack:
        node = stack.pop()
        res.append(node.val)        # 得到 根-右-左
        if node.left:
            stack.append(node.left)
        if node.right:
            stack.append(node.right)
    return res[::-1]                # 反转为 左-右-根

2. 层序遍历（102）

from collections import deque

def levelOrder(root):
    if root is None:
        return []
    res, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        res.append(level)
    return res

变形：之字形层序（103）在奇数层把 level 反转；右视图（199）取每层最后一个元素。

3. 最大深度（104）与翻转二叉树（226）

def maxDepth(root):
    if root is None:
        return 0
    return 1 + max(maxDepth(root.left), maxDepth(root.right))


def invertTree(root):
    if root is None:
        return None
    root.left, root.right = invertTree(root.right), invertTree(root.left)
    return root

4. 平衡二叉树（110）

自底向上：后序位置拿到左右子树高度，若不平衡就返回 -1 一路向上传递，整体 O(n)O(n)O(n)。

def isBalanced(root):
    def height(node):
        if node is None:
            return 0
        lh = height(node.left)
        if lh == -1:
            return -1
        rh = height(node.right)
        if rh == -1 or abs(lh - rh) > 1:
            return -1
        return 1 + max(lh, rh)

    return height(root) != -1

如果对每个节点都单独算一次高度再比较，最坏复杂度是 O(n2)O(n^2)O(n​2​​)，面试时要能说出这一点。

5. 二叉树中的最大路径和（124，Hard）

路径可以从任意节点出发、在任意节点结束。后序位置计算「以当前节点为端点向下延伸的最大单边和」，负数贡献直接舍弃，同时用 左 + 右 + 自己 更新全局答案。

def maxPathSum(root):
    res = float('-inf')

    def one_side(node):
        nonlocal res
        if node is None:
            return 0
        left = max(0, one_side(node.left))
        right = max(0, one_side(node.right))
        res = max(res, left + right + node.val)
        return node.val + max(left, right)

    one_side(root)
    return res

坑：res 初值必须是负无穷而不是 0，因为全是负数时答案是最大的那个负数。

6. 最近公共祖先（236）

后序位置判断左右子树是否各找到一个目标节点，代码和思路见算法分类下的《二叉树的扩展延伸》。

四、复杂度与答题技巧

  • 递归遍历时间 O(n)O(n)O(n)，空间 O(h)O(h)O(h)，h 为树高：平衡时 O(logn)O(\log n)O(logn)，退化成链表时 O(n)O(n)O(n)；
  • 层序遍历空间取决于最宽一层，最坏 O(n)O(n)O(n)；
  • 答题套路：先说清递归函数的定义，再说「当前节点在前/中/后序位置要做什么」，最后补充边界（空树、单节点、链状树）和复杂度。

小结

树相关面试题可以归为三类：概念对比（BST / AVL / 红黑树 / B+ 树的取舍，背后都是「树高」与「IO 次数」的权衡）、遍历手写（递归 + 迭代 + 层序必须熟练）、递归设计（深度、平衡、路径和、LCA，核心都是利用后序位置的子树返回值）。
