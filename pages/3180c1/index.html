sys

01.sys模块是什么

sys 是 Python 的内置模块，提供了访问 Python 解释器本身 的变量和函数：命令行参数、模块搜索路径、标准输入输出、解释器版本、递归深度、退出程序等。

和 os 模块的区别（面试常问）：

  • os：与操作系统交互，比如文件、目录、环境变量、进程。
  • sys：与Python 解释器交互，比如 sys.argv、sys.path、sys.modules。

02.常用属性和方法

import sys

#1 命令行参数列表，第一个元素是脚本本身的路径
print(sys.argv)              # python demo.py a b  ->  ['demo.py', 'a', 'b']

#2 模块搜索路径，import 时按顺序在这些目录里找模块
print(sys.path)

#3 已经导入的模块字典 {模块名: 模块对象}
print('os' in sys.modules)

#4 解释器版本
print(sys.version)           # '3.12.3 (main, ...) [GCC ...]'
print(sys.version_info)      # sys.version_info(major=3, minor=12, micro=3, ...)
print(sys.version_info >= (3, 10))   # 可以直接和元组比较

#5 当前平台：'linux' / 'darwin' / 'win32'
print(sys.platform)

#6 当前 Python 解释器可执行文件的绝对路径（排查虚拟环境问题很有用）
print(sys.executable)

#7 平台上 Py_ssize_t 的最大值，常用作“很大的数”（int 本身没有上限）
print(sys.maxsize)           # 64 位系统上是 9223372036854775807

#8 默认字符串编码
print(sys.getdefaultencoding())   # 'utf-8'

#9 对象占用的字节数（浅层大小）
print(sys.getsizeof([1, 2, 3]))

#10 递归深度上限，默认一般是 1000
print(sys.getrecursionlimit())
sys.setrecursionlimit(3000)

#11 对象的引用计数（结果通常比预期多 1，因为传参本身也是一次临时引用）
a = []
print(sys.getrefcount(a))    # 通常是 2，具体值与解释器版本/实现有关

#12 退出程序
sys.exit(0)

03.sys.argv：命令行参数

# add.py
import sys

if len(sys.argv) != 3:
    print(f"用法: python {sys.argv[0]} <a> <b>", file=sys.stderr)
    sys.exit(1)

a, b = int(sys.argv[1]), int(sys.argv[2])
print(a + b)

$ python add.py 3 4
7

sys.argv 里的元素都是字符串，需要自己转换类型。参数一多就建议用标准库 argparse，它会自动生成帮助信息、做类型校验。

04.sys.path：模块搜索路径

import xxx 时，解释器会依次在 sys.path 的目录中查找。它的来源大致是：

  1. 被运行脚本所在的目录（交互模式下是当前目录）
  2. 环境变量 PYTHONPATH 中的目录
  3. 标准库目录、site-packages 等安装相关的目录

运行时临时添加搜索路径：

import os
import sys

BASE_DIR = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
sys.path.insert(0, BASE_DIR)   # 插到最前面，优先级最高；append 则是最低

import my_package

改 sys.path 只对当前进程生效。项目结构稳定后，更推荐把项目做成可安装的包（pip install -e .），或者用 python -m 包名.模块 的方式运行，而不是到处写 sys.path.append。

05.标准输入输出

sys.stdin、sys.stdout、sys.stderr 是三个文件对象，print() 本质上就是往 sys.stdout 写。

import sys

sys.stdout.write("hello\n")          # 不会自动换行，返回写入的字符数
sys.stderr.write("出错了\n")          # 错误信息应写到 stderr
print("警告", file=sys.stderr)

# 逐行读取标准输入，例如: cat data.txt | python count.py
count = 0
for line in sys.stdin:
    count += 1
print(count)

刷题时读取大量输入的常见写法：

import sys
input = sys.stdin.readline   # 比内置 input() 快，但会保留行尾的 '\n'

n = int(input())
nums = list(map(int, input().split()))

stdout 和 stderr 分开的好处是可以分别重定向：python app.py > out.log 2> err.log。

06.sys.exit 与退出码

import sys

def main() -> int:
    ...
    return 0

if __name__ == "__main__":
    sys.exit(main())
  • sys.exit(0) 或 sys.exit()：正常退出，退出码 0。
  • sys.exit(1)：非 0 表示失败，shell 中可以用 echo $? 查看。
  • sys.exit("错误信息")：把字符串打印到 stderr，退出码为 1。

本质：sys.exit() 并不是直接结束进程，而是抛出一个 SystemExit 异常，所以 finally 块会执行，也可能被捕获：

import sys

try:
    sys.exit(2)
except SystemExit as e:
    print("捕获到退出，退出码:", e.code)   # 2
finally:
    print("finally 仍然会执行")

07.异常信息与 sys.modules

import sys

try:
    1 / 0
except ZeroDivisionError:
    exc_type, exc_value, tb = sys.exc_info()
    print(exc_type, exc_value)          # <class 'ZeroDivisionError'> division by zero
    # Python 3.11+ 可以直接用 sys.exception() 拿到当前异常实例

sys.modules 是模块缓存，同一个模块只会被执行一次，第二次 import 直接从这里取。这也是“模块天然是单例”的原因。想重新加载可以用 importlib.reload(module)。

08.常见坑

  1. 裸 except: 会吞掉 sys.exit()：SystemExit 继承自 BaseException，except Exception 不会捕获它，但 except: 和 except BaseException 会。
  2. sys.getsizeof 只算浅层大小：列表的大小不包含里面元素对象的大小，统计嵌套结构的内存要自己递归或用第三方工具。
  3. setrecursionlimit 不是万能的：设置得过大可能直接导致 C 栈溢出、解释器崩溃。深递归优先考虑改成循环或显式栈。
  4. sys.path[0] 是脚本所在目录：如果你在项目里建了 json.py、random.py 这种与标准库同名的文件，会把标准库“挡住”，导入出错。
  5. sys.argv 都是字符串：sys.argv[1] + 1 会报 TypeError。

09.小结

  • sys 负责与解释器打交道，os 负责与操作系统打交道。
  • 高频 API：sys.argv、sys.path、sys.exit()、sys.stdin/stdout/stderr、sys.version_info、sys.platform、sys.modules。
  • sys.exit() 是通过抛 SystemExit 实现的，finally 会执行。
  • 命令行参数复杂时用 argparse，导入路径混乱时优先整理包结构，而不是堆砌 sys.path.append。
