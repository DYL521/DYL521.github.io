01.什么是三剑客

grep、sed、awk 被称为 Linux 文本处理"三剑客"，它们都按行处理文本，都支持正则表达式，经常通过管道组合使用。

工具 定位 擅长 一句话
grep 过滤/查找 找出匹配的行 查
sed 流编辑器 替换、删除、插入、按行号截取 改
awk 文本分析语言 按列切分、统计、格式化输出 算

选择原则：能用 grep 就不用 sed，能用 sed 就不用 awk——越简单的工具越快、越不容易写错；需要按列处理或计算时再上 awk。

详细用法见本目录下的分篇笔记：Linux正则、grep、sed、awk。本文侧重对比和常用组合。

02.正则基础回顾

三剑客都依赖正则，先区分两种正则语法：

元字符 含义 基本正则（BRE） 扩展正则（ERE）
^ $ 行首、行尾 支持 支持
. * 任意单字符、前一字符 0 次或多次 支持 支持
[] [^] 字符集合、取反 支持 支持
+ ? 1 次或多次、0 次或 1 次 需写成 \+ \?（GNU 扩展） 直接用
{n,m} 次数范围 \{n,m\} {n,m}
()、竖线 分组、或（a 竖线 b） 写成 \(\)、反斜杠+竖线（GNU 扩展） 直接用 ()、竖线
  • grep 默认 BRE，grep -E（即 egrep）使用 ERE。
  • sed 默认 BRE，sed -E（或 GNU 的 sed -r）使用 ERE。
  • awk 默认就是 ERE。

03.grep：查找过滤

grep -n "error" app.log                  # 显示行号
grep -i "error" app.log                  # 忽略大小写
grep -v "^#" nginx.conf | grep -v "^$"   # 去掉注释和空行
grep -Ev "^\s*(#|$)" nginx.conf          # 同上，一条命令
grep -c "500" access.log                 # 统计匹配行数
grep -o "[0-9]\{1,3\}\(\.[0-9]\{1,3\}\)\{3\}" a.txt   # 只输出匹配到的 IP
grep -rn "TODO" --include="*.java" src/  # 递归查找指定类型文件
grep -A 3 -B 2 "Exception" app.log       # 输出匹配行的后 3 行、前 2 行
grep -w "root" /etc/passwd               # 按整词匹配
grep -F "a.b*c" file                     # 按固定字符串匹配，不解析正则

04.sed：流式编辑

sed 的基本格式：sed [选项] '地址 命令' 文件。

sed -n '10,20p' app.log                  # 打印 10~20 行（-n 取消默认输出）
sed -n '/start/,/end/p' app.log          # 打印两个模式之间的内容
sed 's/old/new/' a.txt                   # 每行替换第一个匹配
sed 's/old/new/g' a.txt                  # 全局替换
sed -i 's/8080/9090/g' app.conf          # -i 直接修改文件
sed -i.bak 's/8080/9090/g' app.conf      # 修改前备份为 app.conf.bak
sed '/^#/d;/^$/d' nginx.conf             # 删除注释行和空行
sed '3i\new line' a.txt                  # 在第 3 行前插入
sed '3a\new line' a.txt                  # 在第 3 行后追加
sed 's#/usr/local#/opt#g' a.txt          # 分隔符可以换成 #，避免转义 /
sed -E 's/([0-9]+)-([0-9]+)/\2-\1/' a.txt   # 分组反向引用

常用命令：p 打印、d 删除、s 替换、i 前插、a 后追加、c 整行替换。

05.awk：按列处理与统计

awk 的基本格式：awk -F '分隔符' 'BEGIN{} 条件{动作} END{}' 文件。

常用内置变量：

变量 含义
$0 整行
$1..$n 第 n 列
NF 当前行的列数，$NF 为最后一列
NR 当前行号
FS / OFS 输入 / 输出字段分隔符 
awk -F: '{print $1, $7}' /etc/passwd             # 打印用户名和 shell
awk -F: '$3 >= 1000 {print $1}' /etc/passwd      # UID >= 1000 的普通用户
awk 'NR==5,NR==10' a.txt                         # 打印 5~10 行
awk '{print $NF}' a.txt                          # 打印最后一列
awk '{sum += $3} END {print sum}' data.txt       # 第 3 列求和
awk 'BEGIN{OFS=","} {print $1, $2}' a.txt        # 以逗号输出
awk '/error/ {count++} END {print count+0}' app.log   # 统计 error 行数

awk 的数组（关联数组）非常适合做分组统计：

# 统计 nginx 访问日志中访问次数最多的前 10 个 IP
awk '{ip[$1]++} END {for (i in ip) print ip[i], i}' access.log | sort -rn | head -10

06.三剑客组合实战

# 1. 取出本机 eth0 的 IPv4 地址
ip -4 addr show eth0 | grep inet | awk '{print $2}' | cut -d/ -f1
ip -4 addr show eth0 | awk '/inet /{split($2, a, "/"); print a[1]}'

# 2. 统计 TCP 各连接状态数量
ss -ant | awk 'NR>1 {s[$1]++} END {for (k in s) print k, s[k]}'

# 3. 统计 nginx 日志中状态码分布
awk '{print $9}' access.log | sort | uniq -c | sort -rn

# 4. 批量把配置中的 IP 替换为新地址
grep -rl "192.168.1.10" /etc/myapp/ | xargs sed -i 's/192\.168\.1\.10/192.168.1.20/g'

# 5. 查看占用内存最多的 5 个进程
ps aux --sort=-%mem | awk 'NR>1 && NR<=6 {print $2, $4"%", $11}'

# 6. 查找某时间段的日志
sed -n '/2024-01-01 10:00/,/2024-01-01 11:00/p' app.log

07.常见坑

  1. sed -i 在 macOS 上不同：BSD sed 要求 -i 后跟备份后缀，需写成 sed -i '' 's/a/b/' file；GNU sed 直接 sed -i。
  2. 单双引号：awk 程序要用单引号包住，否则 $1 会被 shell 先展开。需要传 shell 变量时用 awk -v name="$var" '{print name}'。
  3. 正则中的点：sed 's/1.1/x/' 中的 . 匹配任意字符，替换 IP 等字面量时要写成 \.。
  4. sed -i 前先预览：先不带 -i 执行看结果，或使用 -i.bak 留备份。
  5. grep 匹配到自身：ps aux | grep nginx 会匹配到 grep 进程本身，可用 grep [n]ginx 或直接用 pgrep -a nginx。
  6. awk 默认分隔符：默认以连续空白（空格/Tab）分隔，CSV 等格式需显式指定 -F。

小结

  • grep 查：过滤行，常用 -n -i -v -E -o -r -A/-B/-C。
  • sed 改：按行替换/删除/插入，核心是 s/正则/替换/g 和 -n ... p，改文件用 -i。
  • awk 算：按列切分、条件过滤、数组统计，记住 $0 $NF NR NF FS OFS 和 BEGIN/END。
  • 实际工作中三者常与 sort、uniq、cut、xargs 组合，是日志分析和运维脚本的基本功。
