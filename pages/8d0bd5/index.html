Shell基础

操作系统 2021-02-09 · 更新于 2026-11-21 · 7 分钟阅读 · 1716 字

01.什么是 Shell

Shell 是用户与 Linux 内核之间的"翻译官"：它接收用户输入的命令，解释后交给内核执行。我们平时说的"写 Shell"通常指Shell 脚本——把一系列命令写进文件，按顺序批量执行，常用于自动化部署、定时备份、日志分析等运维场景。

常见的 Shell：

Shell 说明
sh Bourne Shell，POSIX 标准；在 Debian/Ubuntu 上 /bin/sh 指向 dash
bash Bourne Again Shell，绝大多数 Linux 发行版的默认 Shell
zsh 功能更丰富，macOS 自 Catalina 起的默认 Shell 
echo $SHELL            # 当前用户的默认 Shell
cat /etc/shells        # 系统可用的 Shell
bash --version

本文以 bash 为准。

02.第一个脚本

#!/bin/bash
# 文件名：hello.sh
echo "Hello, $(whoami)! 今天是 $(date +%F)"

第一行 #!/bin/bash 叫 Shebang，指定由哪个解释器执行。也可以写 #!/usr/bin/env bash，从 PATH 中查找 bash，可移植性更好。

执行方式：

chmod +x hello.sh && ./hello.sh   # 需要执行权限，在子 Shell 中运行
bash hello.sh                     # 不需要执行权限，忽略 Shebang
source hello.sh                   # 在当前 Shell 中运行，等同于 . hello.sh

区别：source 在当前 Shell 执行，脚本中定义的变量、cd 切换的目录会保留下来，所以修改 ~/.bashrc 后用 source ~/.bashrc 使其生效。

03.变量

name="dyl"              # 等号两边不能有空格
echo $name
echo "${name}_blog"     # 变量后紧跟字符时用花括号
readonly PI=3.14        # 只读变量
unset name              # 删除变量
export JAVA_HOME=/usr/local/jdk-21   # 导出为环境变量，子进程可见

today=$(date +%F)       # 命令替换，推荐 $() 而非反引号
count=$((3 + 5))        # 算术运算

3.1 引号的区别

name=dyl
echo '$name'            # 单引号：原样输出 $name
echo "$name"            # 双引号：变量会被替换，输出 dyl

引用变量时尽量加双引号，否则变量中含空格或为空时会出现意想不到的问题。

3.2 特殊变量

变量 含义
$0 脚本名称
$1 ~ $9、${10} 位置参数
$# 参数个数
$@ 所有参数，"$@" 时每个参数独立
$* 所有参数，"$*" 时合并为一个字符串
$? 上一条命令的退出状态，0 表示成功
$$ 当前脚本的进程号
$! 最后一个后台进程的进程号

3.3 字符串操作

str="hello-world.tar.gz"
echo ${#str}            # 长度：18
echo ${str:0:5}         # 截取：hello
echo ${str#*.}          # 从左删除最短匹配：tar.gz
echo ${str##*.}         # 从左删除最长匹配：gz
echo ${str%.*}          # 从右删除最短匹配：hello-world.tar
echo ${str/-/_}         # 替换第一个：hello_world.tar.gz
echo ${var:-default}    # var 为空或未定义时使用默认值

04.条件判断

if [ -f /etc/passwd ]; then
    echo "文件存在"
elif [ -d /etc ]; then
    echo "是目录"
else
    echo "不存在"
fi

[ ] 是 test 命令，括号内两侧必须有空格。bash 中更推荐 [[ ]]，支持 &&、|| 和正则匹配，变量不加引号也更安全。

类型 表达式 含义
文件 -e / -f / -d 存在 / 是普通文件 / 是目录
文件 -r / -w / -x / -s 可读 / 可写 / 可执行 / 非空
整数 -eq -ne -gt -lt -ge -le 等于、不等、大于、小于、大于等于、小于等于
字符串 = / != / -z / -n 相等 / 不等 / 为空 / 非空 
if [[ "$1" =~ ^[0-9]+$ ]]; then echo "是数字"; fi
if (( $# < 2 )); then echo "用法: $0 <src> <dst>"; exit 1; fi

4.1 case 语句

case "$1" in
    start)   echo "启动服务" ;;
    stop)    echo "停止服务" ;;
    restart) echo "重启服务" ;;
    *)       echo "用法: $0 {start|stop|restart}"; exit 1 ;;
esac

05.循环

# for 遍历列表
for host in web01 web02 db01; do
    ping -c 1 -W 1 "$host" &> /dev/null && echo "$host up" || echo "$host down"
done

# C 风格 for
for ((i = 1; i <= 5; i++)); do echo $i; done

# 数字序列
for i in {1..10}; do echo $i; done

# while 逐行读取文件
while IFS= read -r line; do
    echo "行内容: $line"
done < /etc/hosts

# until 直到条件为真
n=0
until [ $n -ge 3 ]; do ((n++)); done

break 跳出循环，continue 跳过本次。

06.函数与数组

# 函数
check_port() {
    local port=$1                    # local 声明局部变量
    if ss -tln | grep -q ":${port}\b"; then
        return 0
    fi
    return 1
}

check_port 80 && echo "80 端口在监听"

# 数组
apps=(nginx mysql redis)
echo ${apps[0]}                      # 第一个元素
echo ${apps[@]}                      # 所有元素
echo ${#apps[@]}                     # 元素个数
for app in "${apps[@]}"; do systemctl is-active "$app"; done

# 关联数组（bash 4+）
declare -A ports=([nginx]=80 [mysql]=3306)
echo ${ports[mysql]}

注意：函数的 return 只能返回 0~255 的状态码，要返回数据请用 echo 输出再通过 $(func) 获取。

07.输入输出与重定向

read -p "请输入用户名: " user        # 读取输入
read -s -p "请输入密码: " pass       # 不回显

cmd > out.log           # 标准输出覆盖写入
cmd >> out.log          # 追加
cmd 2> err.log          # 标准错误
cmd > all.log 2>&1      # 标准输出和错误都写入（顺序不能反）
cmd &> /dev/null        # bash 简写，丢弃所有输出

cat > app.conf <<EOF2
port=8080
env=prod
EOF2

文件描述符：0 标准输入、1 标准输出、2 标准错误。

08.实用示例：日志备份脚本

#!/usr/bin/env bash
set -euo pipefail

LOG_DIR="/var/log/myapp"
BACKUP_DIR="/data/backup"
KEEP_DAYS=7

mkdir -p "$BACKUP_DIR"
file="$BACKUP_DIR/myapp-$(date +%Y%m%d%H%M).tar.gz"

tar -czf "$file" -C "$LOG_DIR" .
echo "[$(date '+%F %T')] 备份完成: $file"

# 删除 7 天前的备份
find "$BACKUP_DIR" -name "myapp-*.tar.gz" -mtime +"$KEEP_DAYS" -delete

配合 crontab 每天凌晨执行：0 2 * * * /opt/scripts/backup.sh >> /var/log/backup.log 2>&1。

09.调试与常见坑

bash -n script.sh       # 只检查语法，不执行
bash -x script.sh       # 打印每条执行的命令，用于调试
set -x / set +x         # 在脚本中局部开启 / 关闭调试

推荐在脚本开头加上 set -euo pipefail：

  • -e：命令失败立即退出。
  • -u：使用未定义变量时报错。
  • -o pipefail：管道中任意一个命令失败，整个管道就返回失败。

常见坑：

  1. 赋值等号两边加空格：name = dyl 会被当成执行 name 命令。
  2. 变量不加引号：rm -rf $DIR/* 中 DIR 为空时会变成 rm -rf /*，务必写成 rm -rf "${DIR:?}"/*。
  3. Windows 换行符：在 Windows 编辑的脚本带 \r，执行报 /bin/bash^M: bad interpreter，用 dos2unix 或 sed -i 's/\r$//' 转换。
  4. crontab 中环境变量缺失：cron 的 PATH 很精简，脚本中使用命令的绝对路径或在开头显式设置 PATH。
  5. sh 与 bash 语法差异：[[ ]]、数组、{1..10} 是 bash 特性，用 sh script.sh 执行（如 Ubuntu 上的 dash）会报错。
  6. 管道中的 while 修改变量：cat file | while read ... 中的循环运行在子 Shell 中，循环结束后变量修改会丢失，改用 while ... done < file。

可以使用 ShellCheck 工具静态检查脚本，能发现大部分上述问题。

小结

Shell 脚本的基础可以归纳为：Shebang 与执行方式、变量与引号、特殊变量、条件判断（[[ ]]、文件/整数/字符串测试）、循环、函数与数组、重定向。写脚本时养成 set -euo pipefail、变量加双引号、先 bash -n / bash -x 调试的习惯，能避免绝大多数线上事故。
