51.N 皇后

N 皇后

  • 难度：困难
  • 题意：在 n×n 棋盘上放 n 个皇后，使其互不攻击（不同行、不同列、不同斜线），返回所有方案。
  • 思路：经典回溯。逐行放置，每行枚举列；用三个集合记录已占用的列、主对角线（r - c 相同）和副对角线（r + c 相同），O(1)O(1)O(1) 判断冲突。时间 O(n!)O(n!)O(n!)。
  • 答案
class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        res = []
        board = [['.'] * n for _ in range(n)]
        cols, diag1, diag2 = set(), set(), set()

        def backtrack(r):
            if r == n:
                res.append([''.join(row) for row in board])
                return
            for c in range(n):
                if c in cols or r - c in diag1 or r + c in diag2:
                    continue
                board[r][c] = 'Q'
                cols.add(c); diag1.add(r - c); diag2.add(r + c)
                backtrack(r + 1)
                board[r][c] = '.'
                cols.remove(c); diag1.remove(r - c); diag2.remove(r + c)

        backtrack(0)
        return res

52.N 皇后 II

N 皇后 II

  • 难度：困难
  • 题意：返回 n 皇后问题不同解决方案的数量。
  • 思路：与 51 相同，只计数不构造棋盘。
  • 答案
class Solution:
    def totalNQueens(self, n: int) -> int:
        cols, diag1, diag2 = set(), set(), set()

        def backtrack(r):
            if r == n:
                return 1
            count = 0
            for c in range(n):
                if c in cols or r - c in diag1 or r + c in diag2:
                    continue
                cols.add(c); diag1.add(r - c); diag2.add(r + c)
                count += backtrack(r + 1)
                cols.remove(c); diag1.remove(r - c); diag2.remove(r + c)
            return count

        return backtrack(0)

53.最大子数组和

最大子数组和

  • 难度：中等
  • 题意：找出和最大的连续子数组，返回其和。
  • 思路：Kadane 算法（动态规划）。cur 表示以当前元素结尾的最大子数组和：要么接在前面，要么自己重新开始，即 cur = max(x, cur + x)。时间 O(n)O(n)O(n)，空间 O(1)O(1)O(1)。
  • 答案
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        cur = res = nums[0]
        for x in nums[1:]:
            cur = max(x, cur + x)
            res = max(res, cur)
        return res

54.螺旋矩阵

螺旋矩阵

  • 难度：中等
  • 题意：按顺时针螺旋顺序返回 m×n 矩阵的所有元素。
  • 思路：维护上下左右四个边界，按「上 → 右 → 下 → 左」遍历一圈后收缩边界。坑：遍历下边和左边前要再次检查边界是否仍然有效，否则单行/单列矩阵会重复输出。
  • 答案
class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        res = []
        top, bottom, left, right = 0, len(matrix) - 1, 0, len(matrix[0]) - 1
        while top <= bottom and left <= right:
            for j in range(left, right + 1):
                res.append(matrix[top][j])
            top += 1
            for i in range(top, bottom + 1):
                res.append(matrix[i][right])
            right -= 1
            if top <= bottom:
                for j in range(right, left - 1, -1):
                    res.append(matrix[bottom][j])
                bottom -= 1
            if left <= right:
                for i in range(bottom, top - 1, -1):
                    res.append(matrix[i][left])
                left += 1
        return res

55.跳跃游戏

跳跃游戏

  • 难度：中等
  • 题意：nums[i] 表示在位置 i 最多能跳的步数，判断能否到达最后一个位置。
  • 思路：贪心，维护能到达的最远位置 farthest；如果当前位置已经超过 farthest，说明到不了。时间 O(n)O(n)O(n)。
  • 答案
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        farthest = 0
        for i, step in enumerate(nums):
            if i > farthest:
                return False
            farthest = max(farthest, i + step)
        return True

56.合并区间

合并区间

  • 难度：中等
  • 题意：合并所有重叠的区间。
  • 思路：按左端点排序，依次与结果中最后一个区间比较，重叠就更新右端点为两者最大值。时间 O(nlogn)O(n \log n)O(nlogn)。
  • 答案
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort(key=lambda x: x[0])
        res = []
        for start, end in intervals:
            if res and start <= res[-1][1]:
                res[-1][1] = max(res[-1][1], end)
            else:
                res.append([start, end])
        return res

57.插入区间

插入区间

  • 难度：中等
  • 题意：向按左端点有序、互不重叠的区间列表中插入一个新区间，必要时合并。
  • 思路：分三段扫描：完全在新区间左侧的直接加入；与新区间重叠的合并进新区间；剩下的直接加入。时间 O(n)O(n)O(n)。
  • 答案
class Solution:
    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        res = []
        start, end = newInterval
        i, n = 0, len(intervals)
        while i < n and intervals[i][1] < start:     # 左侧不重叠
            res.append(intervals[i])
            i += 1
        while i < n and intervals[i][0] <= end:      # 重叠部分合并
            start = min(start, intervals[i][0])
            end = max(end, intervals[i][1])
            i += 1
        res.append([start, end])
        res.extend(intervals[i:])                    # 右侧不重叠
        return res

58.最后一个单词的长度

最后一个单词的长度

  • 难度：简单
  • 题意：返回字符串中最后一个单词的长度（字符串可能有尾随空格）。
  • 思路：从后往前先跳过空格，再数非空格字符。也可以直接 len(s.split()[-1])。
  • 答案
class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        i = len(s) - 1
        while i >= 0 and s[i] == ' ':
            i -= 1
        length = 0
        while i >= 0 and s[i] != ' ':
            length += 1
            i -= 1
        return length

59.螺旋矩阵 II

螺旋矩阵 II

  • 难度：中等
  • 题意：生成一个按顺时针螺旋排列 1 到 n² 的 n×n 矩阵。
  • 思路：和 54 一样维护四个边界，按顺序填数。方阵情况下用 num <= n * n 控制循环即可。
  • 答案
class Solution:
    def generateMatrix(self, n: int) -> List[List[int]]:
        matrix = [[0] * n for _ in range(n)]
        top, bottom, left, right = 0, n - 1, 0, n - 1
        num = 1
        while num <= n * n:
            for j in range(left, right + 1):
                matrix[top][j] = num; num += 1
            top += 1
            for i in range(top, bottom + 1):
                matrix[i][right] = num; num += 1
            right -= 1
            for j in range(right, left - 1, -1):
                matrix[bottom][j] = num; num += 1
            bottom -= 1
            for i in range(bottom, top - 1, -1):
                matrix[i][left] = num; num += 1
            left += 1
        return matrix

60.排列序列

排列序列

  • 难度：困难
  • 题意：返回 1~n 的全排列按字典序排列后的第 k 个。
  • 思路：不要真的枚举排列。以某个数字开头的排列共有 (n−1)!(n-1)!(n−1)! 个，所以第一位是剩余数字中下标为 (k-1) // (n-1)! 的那个，再对余数递推。时间 O(n2)O(n^2)O(n​2​​)。
  • 答案
import math

class Solution:
    def getPermutation(self, n: int, k: int) -> str:
        nums = [str(i) for i in range(1, n + 1)]
        k -= 1                          # 转为从 0 开始
        res = []
        for i in range(n, 0, -1):
            idx, k = divmod(k, math.factorial(i - 1))
            res.append(nums.pop(idx))
        return ''.join(res)

61.旋转链表

旋转链表

  • 难度：中等
  • 题意：将链表每个节点向右移动 k 个位置。
  • 思路：先求长度 n 并把尾节点接到头上成环，k %= n 后，从头走 n - k - 1 步找到新的尾节点，断开即可。坑：k 可能远大于 n，必须取模。
  • 答案
class Solution:
    def rotateRight(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        if not head or not head.next:
            return head
        n, tail = 1, head
        while tail.next:
            tail = tail.next
            n += 1
        k %= n
        if k == 0:
            return head
        tail.next = head                # 成环
        new_tail = head
        for _ in range(n - k - 1):
            new_tail = new_tail.next
        new_head = new_tail.next
        new_tail.next = None            # 断开
        return new_head

62.不同路径

不同路径

  • 难度：中等
  • 题意：m×n 网格从左上角走到右下角，每次只能向右或向下，有多少条路径。
  • 思路：dp[i][j] = dp[i-1][j] + dp[i][j-1]，用一维数组滚动优化，空间 O(n)O(n)O(n)。也可以用组合数 Cm+n−2m−1C_{m+n-2}^{m-1}C​m+n−2​m−1​​。
  • 答案
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [1] * n
        for _ in range(1, m):
            for j in range(1, n):
                dp[j] += dp[j - 1]      # dp[j](上方) + dp[j-1](左方)
        return dp[-1]

63.不同路径 II

不同路径 II

  • 难度：中等
  • 题意：在 62 的基础上，网格中有障碍物（值为 1）。
  • 思路：同 62，遇到障碍物把该格路径数置 0。起点有障碍时 dp[0] 在第一行就会被置 0，自然返回 0。
  • 答案
class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        n = len(obstacleGrid[0])
        dp = [0] * n
        dp[0] = 1
        for row in obstacleGrid:
            for j in range(n):
                if row[j] == 1:
                    dp[j] = 0
                elif j > 0:
                    dp[j] += dp[j - 1]
        return dp[-1]

64.最小路径和

最小路径和

  • 难度：中等
  • 题意：网格中每格有非负数，求从左上到右下（只能向右/向下）路径上数字和的最小值。
  • 思路：dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]，一维滚动；把 dp 初始化为无穷大可以省去第一行的特判。
  • 答案
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        n = len(grid[0])
        dp = [float('inf')] * n
        dp[0] = 0
        for row in grid:
            dp[0] += row[0]
            for j in range(1, n):
                dp[j] = min(dp[j], dp[j - 1]) + row[j]
        return dp[-1]

65.有效数字

有效数字

  • 难度：困难
  • 题意：判断字符串是否是有效数字，如 "2"、"-0.1"、"4."、"-.9"、"2e10"、"-90E3" 有效，"e3"、"1e"、"--6"、"95a54e53" 无效。
  • 思路：一次扫描，用三个标志位：是否出现过数字、小数点、指数符号。规则：符号只能在开头或紧跟 e/E；小数点不能重复，也不能出现在 e 之后；e 之前必须有数字，且 e 之后必须重新出现数字。（也可以用有限状态机）
  • 答案
class Solution:
    def isNumber(self, s: str) -> bool:
        seen_digit = seen_dot = seen_e = False
        for i, c in enumerate(s):
            if '0' <= c <= '9':
                seen_digit = True
            elif c in '+-':
                if i > 0 and s[i - 1] not in 'eE':
                    return False
            elif c == '.':
                if seen_dot or seen_e:
                    return False
                seen_dot = True
            elif c in 'eE':
                if seen_e or not seen_digit:
                    return False
                seen_e = True
                seen_digit = False      # e 后面必须再有数字
            else:
                return False
        return seen_digit

66.加一

加一

  • 难度：简单
  • 题意：用数组表示的非负整数加一。
  • 思路：从末位开始，小于 9 直接加一返回；等于 9 置 0 继续进位；全是 9 时在最前面补 1。
  • 答案
class Solution:
    def plusOne(self, digits: List[int]) -> List[int]:
        for i in range(len(digits) - 1, -1, -1):
            if digits[i] < 9:
                digits[i] += 1
                return digits
            digits[i] = 0
        return [1] + digits

67.二进制求和

二进制求和

  • 难度：简单
  • 题意：两个二进制字符串相加，返回二进制字符串。
  • 思路：和第 2 题「两数相加」一样，从低位开始逐位相加并维护进位，循环条件带上 carry。
  • 答案
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        i, j, carry = len(a) - 1, len(b) - 1, 0
        res = []
        while i >= 0 or j >= 0 or carry:
            total = carry
            if i >= 0:
                total += int(a[i]); i -= 1
            if j >= 0:
                total += int(b[j]); j -= 1
            res.append(str(total % 2))
            carry = total // 2
        return ''.join(reversed(res))

68.文本左右对齐

文本左右对齐

  • 难度：困难
  • 题意：把单词数组排版成每行恰好 maxWidth 个字符，左右两端对齐；空格尽量均匀分配，不能均分时左边多；最后一行以及只有一个单词的行左对齐。
  • 思路：纯模拟。贪心地确定每行能放下的单词 [i, j)（单词长度和 + 至少 j-i-1 个空格 ≤ maxWidth），再按规则分配空格。
  • 答案
class Solution:
    def fullJustify(self, words: List[str], maxWidth: int) -> List[str]:
        res, i, n = [], 0, len(words)
        while i < n:
            j, line_len = i, 0
            while j < n and line_len + len(words[j]) + (j - i) <= maxWidth:
                line_len += len(words[j])
                j += 1
            gaps = j - i - 1
            if j == n or gaps == 0:         # 最后一行或只有一个单词：左对齐
                line = ' '.join(words[i:j])
                res.append(line + ' ' * (maxWidth - len(line)))
            else:
                q, r = divmod(maxWidth - line_len, gaps)
                line = ''
                for k in range(i, j - 1):
                    line += words[k] + ' ' * (q + (1 if k - i < r else 0))
                res.append(line + words[j - 1])
            i = j
        return res

69.x 的平方根

x 的平方根

  • 难度：简单
  • 题意：返回 x 的算术平方根的整数部分，不能用内置指数函数。
  • 思路：二分查找满足 mid * mid <= x 的最大 mid。时间 O(logx)O(\log x)O(logx)。
  • 答案
class Solution:
    def mySqrt(self, x: int) -> int:
        lo, hi, ans = 0, x, 0
        while lo <= hi:
            mid = (lo + hi) // 2
            if mid * mid <= x:
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1
        return ans

70.爬楼梯

爬楼梯

  • 难度：简单
  • 题意：每次爬 1 或 2 个台阶，爬到第 n 阶有多少种方法。
  • 思路：dp[n] = dp[n-1] + dp[n-2]，就是斐波那契数列，两个变量滚动即可。动态规划框架见《动态规划解题套路框架》。
  • 答案
class Solution:
    def climbStairs(self, n: int) -> int:
        a, b = 1, 1         # dp[0], dp[1]
        for _ in range(n):
            a, b = b, a + b
        return a

71.简化路径

简化路径

  • 难度：中等
  • 题意：把 Unix 风格的绝对路径简化为规范路径（处理 .、..、多余的 /）。
  • 思路：按 / 切分，用栈模拟：.. 出栈（栈空则忽略），空串和 . 跳过，其余入栈。注意 ... 是合法的目录名。
  • 答案
class Solution:
    def simplifyPath(self, path: str) -> str:
        stack = []
        for part in path.split('/'):
            if part == '..':
                if stack:
                    stack.pop()
            elif part and part != '.':
                stack.append(part)
        return '/' + '/'.join(stack)

72.编辑距离

编辑距离

  • 难度：中等
  • 题意：通过插入、删除、替换一个字符，把 word1 变成 word2 的最少操作数。
  • 思路：dp[i][j] 表示 word1[:i] 变成 word2[:j] 的最少操作数。字符相同时 dp[i][j] = dp[i-1][j-1]；否则取删除 dp[i-1][j]、插入 dp[i][j-1]、替换 dp[i-1][j-1] 三者最小值加 1。base case：空串变成长度为 j 的串需要 j 步。时间 O(mn)O(mn)O(mn)。
  • 答案
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m + 1):
            dp[i][0] = i
        for j in range(n + 1):
            dp[0][j] = j
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    dp[i][j] = 1 + min(dp[i - 1][j],      # 删除
                                       dp[i][j - 1],      # 插入
                                       dp[i - 1][j - 1])  # 替换
        return dp[m][n]

73.矩阵置零

矩阵置零

  • 难度：中等
  • 题意：若某元素为 0，则将其所在行和列全部置 0，要求原地。
  • 思路：O(1)O(1)O(1) 额外空间做法：用第一行、第一列作为标记数组，事先用两个布尔变量记录第一行、第一列本身是否含 0，最后再处理它们。坑：必须最后处理第一行和第一列，否则标记会被污染。
  • 答案
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        m, n = len(matrix), len(matrix[0])
        first_row = any(matrix[0][j] == 0 for j in range(n))
        first_col = any(matrix[i][0] == 0 for i in range(m))
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = matrix[0][j] = 0
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0
        if first_row:
            for j in range(n):
                matrix[0][j] = 0
        if first_col:
            for i in range(m):
                matrix[i][0] = 0

74.搜索二维矩阵

搜索二维矩阵

  • 难度：中等
  • 题意：矩阵每行升序，且每行第一个数大于上一行最后一个数，判断 target 是否存在。

                p0 += 1
                cur += 1
            elif nums[cur] == 2:
                nums[cur], nums[p2] = nums[p2], nums[cur]
                p2 -= 1
            else:
                cur += 1

76.最小覆盖子串

最小覆盖子串

  • 难度：困难
  • 题意：在字符串 s 中找出能够覆盖 t 中所有字符（包含重复次数）的最短子串。
  • 思路：滑动窗口。need 记录每种字符还缺多少个，missing 记录缺少的字符总数。右指针扩张窗口，左指针在窗口合法时尽量收缩，同时更新答案。时间 O(m+n)O(m+n)O(m+n)，空间 O(k)O(k)O(k)，其中 kkk 是字符种类数。
  • 答案
from collections import Counter


class Solution:
    def minWindow(self, s: str, t: str) -> str:
        need = Counter(t)
        missing = len(t)
        left = 0
        start, min_len = 0, len(s) + 1

        for right, ch in enumerate(s):
            if need[ch] > 0:
                missing -= 1
            need[ch] -= 1

            while missing == 0:
                if right - left + 1 < min_len:
                    start, min_len = left, right - left + 1
                left_ch = s[left]
                need[left_ch] += 1
                if need[left_ch] > 0:
                    missing += 1
                left += 1

        return '' if min_len == len(s) + 1 else s[start:start + min_len]

组合

  • 难度：中等
  • 题意：返回从 1~n 中选择 k 个数的所有组合，组合内不计顺序。
  • 思路：回溯时只从 start 之后选数，避免 [1, 2] 和 [2, 1] 重复。路径长度达到 k 时保存一份副本。时间 O(k(nk))O(k\binom{n}{k})O(k(​k​n​​))，递归空间 O(k)O(k)O(k)。
  • 答案
class Solution:
    def combine(self, n: int, k: int) -> List[List[int]]:
        res, path = [], []

        def backtrack(start):
            if len(path) == k:
                res.append(path.copy())
                return
            for num in range(start, n + 1):
                path.append(num)
                backtrack(num + 1)
                path.pop()

        backtrack(1)
        return res

79.单词搜索

单词搜索

  • 难度：中等
  • 题意：判断单词能否由网格中上下左右相邻且不重复使用的单元格组成。
  • 思路：从每个与首字符相同的格子开始 DFS。访问时临时修改格子作为标记，四个方向搜索完成后必须恢复原值，供其他路径使用。最坏时间 O(mn⋅4L)O(mn\cdot4^L)O(mn⋅4​L​​)，递归空间 O(L)O(L)O(L)，其中 LLL 是单词长度。
  • 答案
class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        m, n = len(board), len(board[0])

        def dfs(r, c, index):
            if index == len(word):
                return True
            if r < 0 or r >= m or c < 0 or c >= n or board[r][c] != word[index]:
                return False

            ch = board[r][c]
            board[r][c] = '#'
            found = (dfs(r + 1, c, index + 1) or
                     dfs(r - 1, c, index + 1) or
                     dfs(r, c + 1, index + 1) or
                     dfs(r, c - 1, index + 1))
            board[r][c] = ch
            return found

        return any(dfs(r, c, 0) for r in range(m) for c in range(n))

class Solution:

81.搜索旋转排序数组 II

搜索旋转排序数组 II

  • 难度：中等
  • 题意：数组可能包含重复数字，经过旋转后判断目标值是否存在。
  • 思路：与不含重复数字的版本类似，先判断哪一半有序。当 nums[left] == nums[mid] == nums[right] 时无法判断有序侧，同时收缩左右边界。平均时间 O(logn)O(\log n)O(logn)，重复值很多时最坏退化为 O(n)O(n)O(n)，空间 O(1)O(1)O(1)。
  • 答案
class Solution:
    def search(self, nums: List[int], target: int) -> bool:
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] == target:
                return True

            if nums[left] == nums[mid] == nums[right]:
                left += 1
                right -= 1
            elif nums[left] <= nums[mid]:
                if nums[left] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1
            else:
                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1
        return False

82.删除排序链表中的重复元素 II

删除排序链表中的重复元素 II

  • 难度：中等
  • 题意：删除排序链表中所有出现过重复值的节点，只保留原本只出现一次的数字。
  • 思路：使用哑节点保护头节点。发现一段相同值后，让 prev 跳过整段；没有重复时才同时推进 prev。时间 O(n)O(n)O(n)，空间 O(1)O(1)O(1)。
  • 答案
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        prev, curr = dummy, head

        while curr:
            if curr.next and curr.val == curr.next.val:
                value = curr.val
                while curr and curr.val == value:
                    curr = curr.next
                prev.next = curr
            else:
                prev, curr = curr, curr.next
        return dummy.next

84.柱状图中最大的矩形

柱状图中最大的矩形

  • 难度：困难
  • 题意：每根柱子宽为 1，求柱状图中能够勾勒出的最大矩形面积。
  • 思路：维护高度单调递增的索引栈。当前高度变低时，被弹出的柱子找到了右边界，栈顶新元素左侧就是左边界；末尾补一个高度 0，确保栈中柱子全部被结算。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。
  • 答案
class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        extended = heights + [0]
        stack = []
        res = 0

        for i, height in enumerate(extended):
            while stack and extended[stack[-1]] >= height:
                h = extended[stack.pop()]
                width = i if not stack else i - stack[-1] - 1
                res = max(res, h * width)
            stack.append(i)
        return res

85.最大矩形

最大矩形

  • 难度：困难
  • 题意：在只包含 0 和 1 的二进制矩阵中，求全由 1 组成的最大矩形面积。
  • 思路：逐行把矩阵压缩成柱状图，heights[j] 表示截至当前行第 j 列连续 1 的高度；每行复用 84 题的单调栈算法。时间 O(mn)O(mn)O(mn)，空间 O(n)O(n)O(n)。
  • 答案
class Solution:
    def maximalRectangle(self, matrix: List[List[str]]) -> int:
        if not matrix:
            return 0

        n = len(matrix[0])
        heights = [0] * n
        res = 0

        def largest_area(values):
            extended = values + [0]
            stack = []
            area = 0
            for i, value in enumerate(extended):
                while stack and extended[stack[-1]] >= value:
                    h = extended[stack.pop()]
                    width = i if not stack else i - stack[-1] - 1
                    area = max(area, h * width)
                stack.append(i)
            return area

        for row in matrix:
            for j, cell in enumerate(row):
                heights[j] = heights[j] + 1 if cell == '1' else 0
            res = max(res, largest_area(heights))
        return res

            if head.val < x:

87.扰乱字符串

扰乱字符串

  • 难度：困难
  • 题意：按照题目给定的递归切分与交换规则，判断 s2 是否可能由 s1 变换得到。
  • 思路：三维动态规划。dp[length][i][j] 表示 s1[i:i+length] 与 s2[j:j+length] 是否互为扰乱串；枚举切分点，分别检查“不交换左右子树”和“交换左右子树”两种情况。时间 O(n4)O(n^4)O(n​4​​)，空间 O(n3)O(n^3)O(n​3​​)。
  • 答案
class Solution:
    def isScramble(self, s1: str, s2: str) -> bool:
        n = len(s1)
        if n != len(s2) or sorted(s1) != sorted(s2):
            return False

        dp = [[[False] * n for _ in range(n)] for _ in range(n + 1)]
        for i in range(n):
            for j in range(n):
                dp[1][i][j] = s1[i] == s2[j]

        for length in range(2, n + 1):
            for i in range(n - length + 1):
                for j in range(n - length + 1):
                    for cut in range(1, length):
                        no_swap = (dp[cut][i][j] and
                                   dp[length - cut][i + cut][j + cut])
                        swap = (dp[cut][i][j + length - cut] and
                                dp[length - cut][i + cut][j])
                        if no_swap or swap:
                            dp[length][i][j] = True
                            break
        return dp[n][0][0]

93.复原 IP 地址

复原 IP 地址

  • 难度：中等
  • 题意：把数字字符串拆成四段，返回所有可能的合法 IPv4 地址。
  • 思路：回溯生成四段，每段枚举 1~3 位；不能有前导零，数值必须在 0~255。段数和位数都有固定上限，因此搜索规模可视为常数，递归深度最多为 4。

class Solution:

        res, parts = [], []

        def backtrack(start):
            if len(parts) == 4:
                if start == len(s):
                    res.append('.'.join(parts))
                return

                backtrack(end)
                parts.pop()

        backtrack(0)
        return res

94.二叉树的中序遍历

二叉树的中序遍历

  • 难度：简单
  • 题意：按照“左子树 → 根节点 → 右子树”的顺序返回节点值。
  • 思路：用显式栈模拟递归。先一路把左节点入栈，再访问栈顶并转向右子树，避免深树导致递归栈溢出。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。
  • 答案
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        res, stack = [], []
        curr = root

        while stack or curr:
            while curr:
                stack.append(curr)
                curr = curr.left
            curr = stack.pop()
            res.append(curr.val)
            curr = curr.right
        return res

95.不同的二叉搜索树 II

不同的二叉搜索树 II

  • 难度：中等
  • 题意：生成所有结构不同、节点值恰好为 1~n 的二叉搜索树。
  • 思路：区间 lo~hi 中每个数都可以作为根；根左侧值构造左子树，右侧值构造右子树，再组合所有左右子树。记忆化避免重复构造相同区间。结果数量与卡特兰数有关，时间和输出空间均为指数量级。
  • 答案
from functools import cache


class Solution:
    def generateTrees(self, n: int) -> List[Optional[TreeNode]]:
        @cache
        def build(lo, hi):
            if lo > hi:
                return [None]

            trees = []
            for root_val in range(lo, hi + 1):
                left_trees = build(lo, root_val - 1)
                right_trees = build(root_val + 1, hi)
                for left in left_trees:
                    for right in right_trees:
                        trees.append(TreeNode(root_val, left, right))
            return trees

        return build(1, n)

  • 难度：中等
  • 题意：计算由 1~n 能组成多少棵结构不同的二叉搜索树。
  • 思路：dp[i] 表示 i 个节点的树数量。枚举根节点，左子树有 root-1 个节点，右子树有 i-root 个节点，两边组合数相乘；结果就是卡特兰数。时间 O(n2)O(n^2)O(n​2​​)，空间 O(n)O(n)O(n)。
  • 答案
class Solution:
    def numTrees(self, n: int) -> int:
        dp = [0] * (n + 1)
        dp[0] = 1
        for nodes in range(1, n + 1):
            for root in range(1, nodes + 1):
                dp[nodes] += dp[root - 1] * dp[nodes - root]
        return dp[n]

97.交错字符串

交错字符串

  • 难度：中等
  • 题意：判断 s3 是否能由 s1 和 s2 交错组成，且两个字符串内部的字符顺序保持不变。
  • 思路：dp[i][j] 表示 s1 前 i 个字符与 s2 前 j 个字符能否组成 s3 前 i+j 个字符。最后一个字符只能来自 s1 或 s2，用一维数组滚动优化。时间 O(mn)O(mn)O(mn)，空间 O(n)O(n)O(n)。
  • 答案
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        m, n = len(s1), len(s2)
        if m + n != len(s3):
            return False

        dp = [False] * (n + 1)
        dp[0] = True
        for j in range(1, n + 1):
            dp[j] = dp[j - 1] and s2[j - 1] == s3[j - 1]

        for i in range(1, m + 1):
            dp[0] = dp[0] and s1[i - 1] == s3[i - 1]
            for j in range(1, n + 1):
                from_s1 = dp[j] and s1[i - 1] == s3[i + j - 1]
                from_s2 = dp[j - 1] and s2[j - 1] == s3[i + j - 1]
                dp[j] = from_s1 or from_s2
        return dp[n]

98.验证二叉搜索树

验证二叉搜索树

  • 难度：中等
  • 题意：判断一棵二叉树是否是有效的二叉搜索树；左、右子树中的所有节点都必须满足大小关系，而不只是直接与根比较。
  • 思路：二叉搜索树的中序序列严格递增。迭代中序遍历时，当前值必须大于前一个访问值。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。
  • 答案
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        stack = []
        curr = root
        prev = None

        while stack or curr:
            while curr:
                stack.append(curr)
                curr = curr.left
            curr = stack.pop()
            if prev is not None and curr.val <= prev:
                return False
            prev = curr.val
            curr = curr.right
        return True

99.恢复二叉搜索树

恢复二叉搜索树

  • 难度：中等
  • 题意：一棵二叉搜索树中恰好有两个节点的值被错误交换，不改变树结构，将它们恢复。
  • 思路：中序遍历本应严格递增。遇到逆序对时，第一个逆序对的较大节点可能是第一个错误节点，后一个逆序对的较小节点是第二个错误节点；最后交换两个节点的值。时间 O(n)O(n)O(n)，显式栈空间 O(n)O(n)O(n)。
  • 答案
class Solution:
    def recoverTree(self, root: Optional[TreeNode]) -> None:
        stack = []
        curr = root
        prev = first = second = None

        while stack or curr:
            while curr:
                stack.append(curr)
                curr = curr.left
            curr = stack.pop()
            if prev and prev.val > curr.val:
                if first is None:
                    first = prev
                second = curr
            prev = curr
            curr = curr.right

        first.val, second.val = second.val, first.val

100.相同的树

相同的树

  • 难度：简单
  • 题意：判断两棵二叉树是否结构相同，并且对应节点的值也相同。
  • 思路：成对遍历节点。两个节点都为空表示这一分支相同；只有一个为空或值不同就立即返回 False，否则继续比较左右子节点。时间 O(n)O(n)O(n)，空间 O(n)O(n)O(n)。
  • 答案
class Solution:
    def isSameTree(self, p: Optional[TreeNode], q: Optional[TreeNode]) -> bool:
        stack = [(p, q)]
        while stack:
            node1, node2 = stack.pop()
            if not node1 and not node2:
                continue
            if not node1 or not node2 or node1.val != node2.val:
                return False
            stack.append((node1.left, node2.left))
            stack.append((node1.right, node2.right))
        return True
